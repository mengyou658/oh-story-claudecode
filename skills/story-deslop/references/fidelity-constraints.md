# 保真与浓度计边界（shuorenhua × hanyu）

> 蒸馏自 `refs/shuorenhua`（说人话 v2.5）与 `refs/694410194__hanyu-skill`（韩愈）。  
> 与 [deslop-process.md](deslop-process.md) / Gate / Never inject **叠加**；不另起可覆盖 `SKILL.md` 的顶级政策。  
> 网文默认走本文件「小说适配」；公众号等短文另见 [shortform-sidepath.md](shortform-sidepath.md)。

目标：去套话与模板，**不**改命题、不编细节、不凭词表命中盲换。浓度计只能做相对比较，不能当作者身份证明。

---

## 1. 保真硬约束（说人话）

### 必须保留

| 类别 | 要求 |
|------|------|
| 命题与关系 | 谁做什么、数字含义、条件、范围、否定、情态、完成状态、比较方向；不把几种具体改善压成「更好」 |
| 抽象也算内容 | 原文只谈潜力/目标/作用时保持抽象；**不**补实现、数据或新对象；缺细节不构成整条删除许可 |
| 责任与下一步 | 清推销语气时，谁交付、交付什么、条件、「可以」仍在；不改成要求对方先补材料 |
| 专名与代码 | 数字、版本、命令、路径、接口名、代码块（含注释/文档字符串）默认逐字保留；改注释须用户点名 |
| 作者口气 | 经历、立场、犹豫、有意重复、合理转场不是空话；勿替作者更自信/更热情/更像公告 |
| 被讨论的套话 | 报道、引用、吐槽某种宣传说法 ≠ 作者在宣传；保留「谁如何宣称」，不把被讨论内容当套话删 |

### 默认可删（仅当不承担独有内容）

- 纯招呼、致谢、无主题/无承诺的预告
- 只提示写法或行文顺序的路标（「值得注意的是」类），**保留它引出的内容**
- 完整重复（保留部分须已完整表达同一内容；相关/可推断 ≠ 重复）
- 无依据的读者身份认证（「你已经是资深专家」）；感受/心理/进展/方案评价**不**并入认证语一起删

### 编辑范围（用户优先）

| Scope | 可以 | 默认场景 |
|-------|------|----------|
| `structural` | 删、并、重排；仍保有效信息与意图 | 清理档默认；短文未指定时 |
| `bounded` | 句内清理；不删整句、不并句、不重排；空句可列「建议删除（待确认）」 | 用户说少改 / 保留结构 |
| `in-place` | 仅句内替换或删修饰；要求保句数时也不拆句 | 用户说只在原位改 |

`minimal / standard / aggressive` **只**表示幅度，不放宽保真。中文公开长文约 1000 字以上默认偏 `bounded`（短文旁路可放宽）。

### 引号按用途

| 用途 | 处理 |
|------|------|
| 依据原话、文献、规范、界面文字、正在定义的词、书名号标题 | 原文保留 |
| 叙述中的人物讲话 | 可清口头填充/重复；保留事实、判断与「可能/我觉得」等情态 |
| 普通名词「引号强调」 | 按 [anti-ai-writing.md](anti-ai-writing.md) 引号规则审查，不因带引号跳过 |

### 无源论断（场景分流）

原文「研究表明 / 专家认为」等未指明来源时：

| 场景档 | 默认 |
|--------|------|
| **novel**（网文叙述） | 叙述层模糊归因按 Gate G：**删**或压成角色可见信息；不编造出处 |
| **article / 短文旁路** | **保留归属+论断**，可正文外注缺来源；不可只剥归属把结论写成裸事实。用户明确 `rewrite-safe` 才可删整条无源论断 |

### 交付前核对（说人话）

1. 逐句对照改动：被删/换的实词、限定、关系若不再表达，且非授权删除或完整重复 → 放回  
2. 无新增断言、无语义漂移、未越 scope  
3. 拿不准就撤销该处；不靠追加解释掩盖  
4. 默认只交正文（检测/标注模式除外）；必要提示与删除建议放正文后

## 2. 浓度计边界（韩愈 / hanyu）

**是浓度计，不是试金石。** 与 [deslop-process.md](deslop-process.md) Detector boundaries 一致，并补充：

| 能做 | 不能做 |
|------|--------|
| 改前 vs 改后相对比较 | 判定单篇是否 AI 生成 |
| 长文里定位更「模板」的段落 | 给小红书/公文/跨写手文本打可信绝对分 |
| CI：「不能比上一版更重」 | 把讨论 AI 味、列举禁用词的文章当「使用」计分 |

**领域黑话误伤**：AI/自媒体/商业/技术主题里「闭环、复盘、沉淀、链路、引擎、场景」常是内容需要的通用词，不是自动删除目标——须成簇且代替具体事件才修（与 scan-lexicon 题材白名单一致）。此类文本只看相对降幅，不看绝对值。

可选脚本（不替代本仓 Gate / `slop_gauge.py`）：

```text
python refs/694410194__hanyu-skill/scripts/hanyu_detect.py <file.md>
```

单工具分数**不得**单独否决策略；报告可写「改前 X → 改后 Y」作参考。

## 3. 改写动作：真删 · 不编 · 乱节奏（网文适配）

### 真删，不换汤

把「首先」改成「首先呢」、把黑话换成另一个黑话，比原文更假。  
连接词 / 万能开场 / 段尾升华 / 空洞程度副词：**优先删除**，不是同义替换。

### 不编细节（覆盖 hanyu「补」斧于网文）

hanyu 非虚构要求「每段补具体物」。**网文禁止**：

- 用户/原文没给的数字、人名、机制、出处 → **不造**；标 `[需复核：缺具体物]` 或删空转句  
- 「补不出来就整段删」仅适用于**无剧情功能的空转段**；有伏笔/钩子/因果 → 降 AI 重写，遵守删除比例与 C 级禁动  

允许：把原文已有的物件、动作、对话、数字**推到前台**，替换空洞副词与抽象升华。

### 乱节奏（与本仓自然文本基准对齐）

- 句长参差；禁通篇同模「短钩→解释→小转折→金句」  
- 重要信息不必段段首句点题；可藏进段中（网文章尾仍用动作/对话/悬念，**不**强制「明确立场」式议论文收束）  
- 允许口语转折与留白；**禁止**乱加「呀哦呢哈」造口语  

硬句长配额（如「单句 ≤30 字」）只作短文旁路参考；小说服从 [anti-ai-writing.md](anti-ai-writing.md) 规则 3 与本书文风句长带。

### 三条禁令（两源合流）

1. **不许改事实** — 数字、结论、案例、情态强度不顺手改写  
2. **不许编细节** — 同 Never inject  
3. **不许为口语而口语** — 不堆语气词、不碎句化骗「人味」

## 4. 自检三问（轻量，无脚本时）

1. 我会用这么完整啰嗦的句式跟朋友说话吗？  
2. 这一段有没有一个原文已有、推到前台的具体物？  
3. 删掉路标/升华后，命题与情态还在吗？  

三问里两问答不上 → 再改一轮；仍不确定 → `[需复核]`，不硬改。
