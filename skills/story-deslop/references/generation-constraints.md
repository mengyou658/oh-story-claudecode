# 生成阶段硬约束（写前）

**在落笔正文之前**应用。蒸馏自 novel-write-produce `anti-ai-generation` 与本仓自然文本基准。

目标是落在**人类写作区间**，不是「AI 的反面」——允许平淡句与偶发公式；全篇换成另一种机械指纹也算失败。不授权用噪声造「人味」。

写后去味仍走 `story-deslop` Gates；本文件减少生成阶段就埋下的模板节奏。

## Severity triage

| 级别 | 例子 | 处理 |
|------|------|------|
| 强信号 | 开场八股、三段升华、与无人争辩、元导航预告 | **单次命中即改** |
| 弱信号 | 单个破折号、单个被动、单个程度副词 | 同段 **≥2** 个弱信号或成簇再动 |

## Hard constraints

1. **No stock openings** — 禁「在当今时代 / 随着…的发展 / 在这个…的时代 / 众所周知」类开场（角色反讽对话除外）。
2. **No forced triad** — 两项优于「A，B，更是 C」；禁叙述里的「首先/其次/再次/综上」骨架。
3. **No hollow uplift endings** — 禁段尾金句：「这就是…的力量 / 唯有…方能… / 让我们一起…」
4. **No throat-clearing** — 删「值得注意的是 / 不可否认 / 总而言之」及同类清嗓。
5. **Concrete subjects** — 人/角色做事；禁「时代/科技/命运」空用作动词主语。
6. **Rhythm variance** — 句长参差；禁全章重复「短钩→解释→小转折→金句」段模。
7. **Trust the reader** — 直陈；少「如我们所见」式手把手。
8. **No pull-quote narration** — 像海报的句子改回场景或有缺陷的对话。
9. **Show over label** — 禁叙述者「他很愤怒／她意识到这意味着」空贴标签（有后果的直写情绪可留）。
10. **Originality** — 不仿在世作者可识别表达；只学抽象技法。
11. **No phantom debate** — 删「我不是说…／别误会…／有人可能会觉得…但」——文中未出现的假想反驳。
12. **No meta-joiners** — 删「下文将／Hint:／Plot twist:」等结构预告。
13. **Wh- openers** — What/Why/How 起句成串时，改为主语+动词直陈。
14. **Reader in the room** — 「人们／无人／这件事告诉我们」→ 具体人+动作。

## 中文生成附加

- 叙述句宜短；过长多从句优先拆句（参考 ≤40 字/句，非死配额；本书文风句长带优先）。
- 段落要有过渡，禁提纲式拼接；能叙述的不做项目清单（细纲情节点除外，且勿写成说明文目录）。
- 不为文采而文采；克制感叹号与刻意金句。

## 写前密度上限（de-AI / humanizer-zh-plus）

> 蒸馏自 `refs/gitliuyun__De-AI-Prompt-Enhancer-Writer-Booster-SKILL` 与 humanizer-zh-plus。写前自检；超限先改结构再动笔。逐字引文、角色台词内的自然口语、题材设定专名除外。

| 项 | 上限 | 修法 |
|----|------|------|
| 二分对照壳（不是 A 而是 B / 不在于 A 而在于 B） | 全文 ≤1 | 直接写后项或动作对比 |
| 路标词（更关键/换句话说/事实上/值得注意/总之/与此同时） | 合计 ≤2 | 删，直陈 |
| 关联句式（一旦…就 / 只有…才 / 无论…都 / 随着…的 / 正是因为…所以 / 通过…来） | 合计 ≤2 | 改隐性逻辑或轻量黏合 |
| 极值判断（最…的地方在于 / 真正…的是 / …之处在于 / 更…的是） | ≤1 且须跟可核对事实 | 删框架留事实 |
| 伪学术/黑话（底层逻辑/赛道/闭环/抓手/范式/舆论场/宏大叙事） | 合计 ≤1 | 换成具体事物；题材专名白名单除外 |
| 戏剧化揭露（遮羞布/扯下/戳穿/剥开+表象） | 正文清零 | 删隐喻 |
| 分析师步骤承接（把 X 理完，再 Y / 先看 A 接着看 B） | 清零 | 从事实/场景起笔 |
| 段落同构（观点+解释+段尾总结） | 禁连续 3 段 | 改信息进入方式 |
| 协作泄漏（作为 AI / 希望这能帮助你 / 接下来我们将） | 清零 | 删 |

**修补顺序**（与 deslop good-writing 一致，更细）：结构 → 语气 → 句式 → 词语。

中文原生模式 25–33 详见 [chinese-native-patterns.md](chinese-native-patterns.md)。

## 网文允许

- 短句、章末钩子服务追读时允许；机械堆叠再修。
- 题材词（境界名等）允许；仅当黑话**代替**具体事件时处理。
- 对照 deslop「自然文本基准」：段长随 beat 变化、少公式对话标签、少连续排比。

## Quick pre-flight

- [ ] 开场是场景/冲突，不是论文题
- [ ] 叙述无三段口号与段段升华
- [ ] 无与无人争辩、无元导航
- [ ] 角色不会用同一套光滑书面腔说话
- [ ] 写前密度上限未超（二分/路标/关联/极值/黑话/揭露/步骤承接）
- [ ] 未注入假经历或假数据（Never inject：见同 skill / agent-references 的 `deslop-process.md`）
