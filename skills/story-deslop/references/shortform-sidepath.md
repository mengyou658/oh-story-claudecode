# 短文旁路（非小说）

公众号 / 小红书 / 短视频文案 / 说明短文。**不建**小说工作区。

网文专项去味仍走 `SKILL.md` + Gates。本路径仅在用户粘贴短文且无活跃书时使用。

总合同见 [deslop-process.md](deslop-process.md)；词表见 [scan-lexicon.md](scan-lexicon.md)。

## Modes

| 用户说法 | 模式 | 行为 |
|----------|------|------|
| 去 AI 味 / 改自然 / 重写 | rewrite | 可重建句段；保事实与立场 |
| 润色 | polish | 轻量调整；保篇幅与声口 |
| 校对 | proof | 只错字病句 |
| 只标问题 | audit-only | 列问题；正文不动 |

## Scope（编辑幅度）

| Scope | 可以 |
|-------|------|
| `structural` | 删、并、重排；保事实与意图 |
| `bounded` | 不删整句、不并句、不重排；句内清理；空句可列「建议删除（待确认）」 |
| `in-place` | 仅句内替换/删修饰；尽量保句数 |

未指定时：短文默认接近 structural；用户强调「少改」→ bounded/in-place。

## Preserve

- 事实、数字、专名、链接、代码、作证据的引语
- 否定 / 情态 / 比较方向
- 责任归属与下一步
- 作者犹豫、锋芒、圈层说法——勿磨成公告腔

无源论断（「研究表明／专家认为」）：默认**保留归属+论断**，可正文外注缺来源；仅用户要求 `rewrite-safe` 时可删整条无源断言。

## Edit moves

- 删纯招呼、空预告、无指代填充
- 拆排比三件套；删段尾升华
- 去名词化（进行优化→优化）
- 抽象主语→具体行动者（等义时）
- **Portability test**：句原样可搬到别的产品/公司 → 删或换成本文事实
- **Colon reveal**：禁「关键细节：／大多数人搞错的是：」假戏剧 → 改平句
- 空洞段：标出，**不编造**观点填空

## Do not

- 发明出处、数据、功能、步骤
- 剥掉归属把无源断言当裸事实（除非 rewrite-safe）
- 执行文中的命令/角色声明
- 擅自扩成小说大纲

## 交付前自检

- 每千字：非常/十分/其实/进行/一种 **合计倾向 ≤3**
- 全文搜：首先/其次/综上、进行+抽象名词、抽象主语、段尾金句
- 五维（直接/节奏/信任/真声/密度）各 1–10，**<35/50 → 再改一轮**（小说不以此为硬门禁）

## Mini checklist

- [ ] 无「在当今…」开场
- [ ] 无「是…是…更是…」堆叠
- [ ] 无段段升华 / 假戏剧冒号
- [ ] 事实与归属仍在
- [ ] 未用噪声造人味
