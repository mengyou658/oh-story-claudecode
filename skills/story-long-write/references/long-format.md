# 长篇正文格式

> 表达默认值服从 [style-resolution.md](style-resolution.md)；文件结构与事实约束不豁免。

> 只约束长篇章节的段落、对话、标点与工程元信息。短篇 `###1.` 小节、8–15 节全文结构和 500–800 字/节口径不适用。

## 章节与段落

- 章节标题、编号和文件名服从项目既有格式；正文内部不再重复章节号。
- 按戏剧单元、镜头变化、新行动、新信息或新对话自然断段，不按固定字数切段。
- 短段是节奏工具，不是默认模板；完整推理、氛围和情绪因果可以使用长段。
- 爽点、转折和关键选择写密，过场、赶路与已知信息连接写疏；不要让每个 beat 一样长。
- 段首需要时点名角色，段中使用代词、省略或动作承接；不要每句机械重复角色名。
- 正文相邻段落之间只允许一个换行符 `\n`，不得出现空行或连续换行 `\n\n`。
- 正文不缩进，不使用 `　　`（全角空格）或半角空格开头。

## 对话

- 引号风格服从项目/平台约定，全章统一；未指定时使用半角双引号。
- 对话独立成行，动作承接放在同一角色的话前后，不把每句都标成“他说/她道”。
- 问号用于真实疑问、质问或反问；感叹号只留给爆发峰值，不连用。
- 停顿、犹豫、吞咽、打断或拖长用动作、短句、换行或未完成句承担；正文和对话不使用省略号、破折号作万能停顿。
- 台词必须改变信息、关系、策略或权力位置；整段设定讲解改成问答、试探、反驳或行动后果。

## 长篇章级约束

- **不按目标字数生成**：细纲 `字数目标` 与 ±12%/±15% 带只作规划参考；**生成多少就是多少**，不以 2000 或目标带为由加厚。
- 默认 **3 章细纲合并为 1 章正文**（见 [local-production-rules.md](local-production-rules.md)）；批准情节写完即停，**禁止用水话回填**；优先**紧凑快节奏**。
- 先核批准情节点是否落地；漏点只补批准内容。情节已齐则停——不得为凑字新增事件/角色/规则，也不得加厚已批情节点。
- 人味/去AI/净删后变短可接受（少了就少了，不回灌）。
- **最终正文＝去味后**：每章首次落盘后同轮执行 story-deslop 写后定稿模式，用人味稿覆盖 `正文/第XXX章_*.md`；该路径才是定稿（见 local-production-rules §4）。
- 明显注水超长时可净删一次重复解释/无功能微动作；不删批准情节点、因果、选择、兑现与钩子。
- 每章定稿（去味覆盖后）把实际字数写入 `追踪/字数记录/第XXX章.md`（独立账本，不触发改写）。
- 章节可以包含多个场景或 beat，数量由细纲和因果决定；不套短篇全文小节数。

## 工程元信息隔离

- 标题行以外，正文叙述、对话和心理描写不得出现“本章、上一章、前文、后文、伏笔、细纲、读者”等写作工程词。
- 需要承接时改成角色可感知的事件锚点或相对时间；角色在故事世界内真实讨论章节/读者身份时例外。
- 正文不使用加粗、斜体、分隔线或检查报告；合法章节标题除外。

## 交付检查

- [ ] 段落按镜头与行动变化断开，不是固定句数模板，段间没有空行、没有缩进。
- [ ] 引号、问号、感叹号和停顿方式全章一致。
- [ ] 长篇字数：不追目标；不加厚；改短可接受；禁止水话回填；默认三纲并一文；`追踪/字数记录/第XXX章.md` 已写入。
- [ ] 正文没有写作工程元信息、自检或说明。
- [ ] `追踪/章号映射.md` 已更新正文进度与细纲消费进度。
