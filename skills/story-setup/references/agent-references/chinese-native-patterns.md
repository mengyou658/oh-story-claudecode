# 中文原生 AI 模式（25–33）

> 蒸馏自 `refs/Chendestiny__humanizer-zh-plus`（基于 op7418/Humanizer-zh 24 类基座之上的中文特有套路）。  
> 24 类基座索引见 [anti-ai-writing.md](anti-ai-writing.md)；本文件只收 **25–33** 与网文改写原则。  
> 表达默认服从 [style-resolution.md](style-resolution.md)；剧情/C 级禁动优先于机械替换。

场景档差异见 [scene-profiles.md](scene-profiles.md)。机械读数对齐 [slop-gauge-thresholds.md](slop-gauge-thresholds.md)。

## 25. 四字格堆砌

**识别**：连续两个以上四字短语（与此同时、毋庸置疑、持续深化、凝心聚力、深度赋能…）或同段落密集堆叠。

**为什么是 AI 味**：四字格在训练语料里代表「正式书面体」，LLM 用它制造高级感；真人写作只在刻意公文模仿时连用。

**改写**：换成具体主谓句或直接给观点。「持续深化 AI 技术应用」→「AI 这几年确实在往深处用」。

**Gate**：A（词）/ B（成簇）

---

## 26. 文言虚词滥用

**识别**：「其核心在于 / 乃因 / 则需 / 之所在」；现代白话里连用「其」字指代（其强大的功能 / 其卓越的性能）。

**改写**：「其」→「它 / 这」，整句改主动直陈。

**Gate**：B；扫描见 [scan-lexicon.md](scan-lexicon.md)「其/该/此」

---

## 27. 机械三连排比

**识别**：是…是…是 / 有…有…有 / 能…能…能 / 为…为…为 三连，结构完全平行、长度相近；以及「在于…，在于…，在于…」判断排比（slop-gauge `judgment_triads`）。

**改写**：破掉一项，或换直接陈述。

**Gate**：B / D

---

## 28. 套路开头模板

**识别**：「随着…的（发展/普及/兴起）/ 在这个…的时代 / 在数字化浪潮席卷全球的当下 / 众所周知 / 不得不说 / 毋庸置疑」。

**改写**：删掉铺垫，直接给观点、事实或场景。

**Gate**：F（开场八股）+ 写前 [generation-constraints.md](generation-constraints.md) #1

---

## 29. 套路结尾模板

**识别**：「综上所述 / 总而言之 / 一言以蔽之 / 展望未来 / 让我们共同期待 / 开启…新篇章 / 希望对您有所启发」。

**改写**：删模板句，用下一步动作、物件或未解决问题收尾。

**Gate**：F；slop-gauge `lift_end`

---

## 30. 伪深度空转

**识别**：「本质上 / 从深层逻辑看 / 值得深思 / 细思极恐 / 彰显着……的智慧」——读起来深刻，抽掉主语什么都没剩下。

**改写**：每句抽象主张配一个具体事实或例子；给不出的整句删。

**Gate**：G（偏解释/升华旁白）

---

## 31. 工作汇报腔

**识别**：「扎实推进 / 切实提升 / 进一步强化 / 健全完善 / 压紧压实 / 形成闭环」及「动词 + 四字宾语」公文动词组。

**改写**：换成「谁对什么做了什么，量是多少」。

**Gate**：A / B；scan-lexicon 名词化/黑话

---

## 32. 虚假跨度

**识别**：「从入门到精通」「从想法到落地」「从 0 到 1 再到 100」——X 和 Y 不在真实旅程上。

**改写**：删跨度，说实际覆盖了什么。

**Gate**：B；scan-lexicon「假范围」；slop-gauge `from_to_jumps`

---

## 33. 段落节奏均匀

**识别**：连续 3+ 段，每段 2–3 句、句长句构相似；每段结尾都是等长的短句号断。

**改写**：允许一句成段；允许一段铺很长；段尾收束方式换着来。机器读数：句长 CV 与 `max_equal_run`（见 slop-gauge）。

**Gate**：D

## 附加可迁移模式（基座 / stop-slop / de-AI）

下列不占 25–33 编号，但网文叙述层常踩：

| 模式 | 信号 | 修法 | Gate |
|------|------|------|------|
| 系动词回避 | 作为/充当/标志着/拥有（夸张）/设有 绕开「是/有」 | 简化系词结构 | B |
| 同义词循环 | 同指代物连续换称呼（主人公→主要角色→中心人物） | 统一指代 | B |
| 无生命施事 | 「命运安排 / 规则不允许 / 系统判定」无施事 | 落到具体人/面板文案 | G/B |
| 协作泄漏 | 作为 AI / 希望这能帮助你 / 接下来我们将 | 删 | A（1A） |
| 步骤承接 | 「把 X 理完，再 Y」「先看 A 接着看 B」 | 删前半，从事实起笔 | B |
| 戏剧化揭露 | 遮羞布/扯下/戳穿/剥开+表象 | 删隐喻，给事实 | G |
| 极值判断框架 | 最…的地方在于 / 真正…的是 / …之处在于 | 删框架留事实；全文 ≤1 | G |
| 关联句式堆叠 | 一旦…就 / 只有…才 / 无论…都 / 正是因为…所以 | 合计 ≤2 | B |
| 无立场退让 | 因人而异 / 视情况而定 / 各有优劣 | 叙述层删或给具体判断；角色真犹豫可留 | G/B |
| 真删不换汤 | 「首先→首先呢」/ 黑话换黑话 | 直接删；见 fidelity-constraints | A |

密度硬门槛见 [generation-constraints.md](generation-constraints.md)「写前密度上限」。保真与浓度计边界见 [fidelity-constraints.md](fidelity-constraints.md)。
