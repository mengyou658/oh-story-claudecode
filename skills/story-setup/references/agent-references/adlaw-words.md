# 广告法极限词替换对照表（v1.0.0）

改写期内一次性替换，不做事后补丁。原则：**合规不是换温和形容词，是写具体事实**——数字、范围、口径永远比宣称安全。

| 违禁表述 | 合规改写方向 | 示例 |
|---|---|---|
| 国家级认证 | 写具体认证名称与文号 | "国家级认证" → "通过 GB/T xxx 标准检测（报告号）" |
| 最高级 / 最佳 / 最好 \| 顶级 | 限范描述 | "最好用" → "本次评测的 7 款里第一"（列样本） |
| 全网最低价 | 写对比口径 | "全网最低" → "比价三平台，现价最低"（附时点） |
| 史上最… | 删宣称，写实测 | "史上最强续航" → "实测 3.2 周不用充电" |
| 无敌 / 万能 | 删，写适用范围 | "万能清理工具" → "清缓存/清残留/清安装包，三件事" |
| 纯天然 | 写成分 | "纯天然成分" → "成分表：芦荟提取物、甘油（无添加防腐剂）" |
| 100%有效 / 根治 | 写实验口径 | "100% 有效" → "200 人试用 185 人反馈改善" |
| 无效退款（无法兑现） | 写机制 | "无效退款" → "14 天无理由退货，流程见详情页" |
| 首个 / 独家 / 唯一 | 限范或删 | "独家配方" → "自研配方（专利号）" 或删 |
| 专家推荐 | 写具体人/机构 | "专家推荐" → "某某医院某某 2025 年临床试验合作" |

通用原则：

1. **能给数字就给数字，能给口径就给口径**——合规词表只是下限，具体事实才是上限
2. 引用声称（认证、临床、专利）**必须有出处**，没有就删整句——宁可弱卖点不可造事实
3. 改后跑 slop-gauge `--profile ecommerce`，adlaw 计数应为 0
