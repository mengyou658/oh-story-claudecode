## 全书情绪节奏总览

- 情绪折线：死亡压迫重生(1) → 截胡爽+抽卡蓄势(2) → 街溜子发育(3) → 赌命窃取爆发(4) → 现实杀人冷静爽(6) → 清家金钱爽(8) → 改运砍臂(11-12) → 雇凶半杀峰值(14) → 二次内测扫货(17-20) → 日常演戏蓄力(21-32) → 窃食神大高潮(33-34) → 旧仇真相(37) → 卖运变现(41-46) → 官方上门(47-48) → 异界练级滚雪球(51-55) → 团灭打脸(57-58) → 契约谈判收束(59-60)
- 爽点频率：约每2-3章一小爽（偷属性/演戏成功）；每内测窗口一中高潮；大高潮在第4/14/19-20/33-34/57-58章
- 高潮分布：小高潮：第3/8/11/27/42章；中高潮：第6/14/20/38章；大高潮：第4、33-34、57-58、60章
- 冲突升级路径：截胡弟弟 → 杀经纪人/刘洪生 → 清家偷苏 → 梁家利息 → 苏家劫金割耳 → 韩家索罗斯 → 截食神 → 官方入游 → 民间据点团灭
- 伏笔跨章地图：
  - 弟弟吸血/剥夺天赋 | 第1章埋 → 第14/33-37章持续回收
  - 盗神技能2一生一次 | 第2-3章立 → 第4章城主/第20章护卫长使用并刷新规则
  - 残缺不朽 | 第4-5章得 → 后续死灵/复活支撑现实搞事
  - 密室黄金 | 第7章回忆 → 第8章清空 → 第16章港城变现
  - 命运齿轮 | 第10章锁定 → 第11章到手 → 第22章伪装演示 → 第41-46章卖运
  - 索罗斯部件 | 第9章面罩 → 第11章眼镜 → 第27章礼帽合成怀表
  - 食神白嫖气运 | 第34章顿悟 → 第37章拆穿上辈子做饭局
  - 官方入游 | 第47-48章谈 → 第49-60章履约谈判

## 循环单元

- 小循环（约2-4章）：锁定目标 → 潜入/偷窃/演戏 → 到手或半杀 → 反应层/新缺口
- 中循环（约一次内测窗口）：备物资 → 截胡登录 → 扫货/窃天赋 → 关服确认现实收益
- 大循环（约卷一）：截胡立外挂 → 现实复仇清本金 → 三次内测毁男主核 → 官方变现进异界
