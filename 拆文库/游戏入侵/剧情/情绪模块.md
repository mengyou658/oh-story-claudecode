## 可复现模块卡

### EM-001 重生截胡发外挂

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 仇人准备起飞的前一秒被主角掐死机缘 |
| 情绪链 | 死亡压迫 → 倒计时狂奔 → 剥夺动作落地 → 抽卡橱窗蓄势 → S级选定 |
| 戏剧单元 | 开局兑现剥夺 + 金手指仪式感发放 |
| 关键触发物 | 精确时刻、仇人近在咫尺、备选A级对比、S级授予词 |
| 复现步骤 | 1.用死亡/失败开场 2.给出不可延误的窗口 3.先完成剥夺再成长 4.亮备选项再发顶级 5.发糖后立刻资源缺口 |
| 可替换项 | 游戏名、天赋名、仇人身份、种族选择 |
| 不可照搬 | 盗神专名、歌屋恩ID、具体内测钟点原文桥段 |
| 关联节奏 | RH-001 / TR-001 / TR-002 |

## 重组与复现指南

1. 先选需求（复仇/截胡/变现），再选 EM 卡。
2. 保留情绪链与功能位，替换金手指、家族、内测次数、官方名。
3. 至少改：仇人关系、截胡手段、变现市场、余波方向中的三项。
4. 日常蓄力段必须穿插「当面演戏」或「小额偷窃」，避免纯囤货流水账。
