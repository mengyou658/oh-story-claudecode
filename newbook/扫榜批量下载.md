## 番茄下载器用法（已验证 v2.4.15）

工具：`F:\book\TomatoNovelDownloader-Win64-v2.4.15.exe`  
输出格式：`config.yml` 里已是 `novel_format: txt`（可直接下 txt）。

### 结论

| 方式 | 能否新建下载 | 说明 |
|------|--------------|------|
| CLI `--download <book_id>` | ❌ | 防滥用已禁用 |
| CLI `--update <book_id>` | 仅已下过的书 | 本地无记录会拒绝 |
| TUI（双击） | ✅ | 交互下载 |
| Web UI `--server` | ✅ **推荐批量** | 支持按章节区间 |

**批量自动化请用 Web UI API，不要用纯 CLI。**

### 推荐流程

```powershell
# 1. 启动（在 F:\book 目录）
.\TomatoNovelDownloader-Win64-v2.4.15.exe --server
# 浏览器：http://127.0.0.1:18423/

# 2. 保存目录改为项目 book（可选，POST /api/config/full 改 save_path）
# 3. 按 bookId 创建任务（前60章）：
# POST http://127.0.0.1:18423/api/jobs
# {"book_id":"7672596897554517054","range_start":1,"range_end":60}
```

注意：

- 同时只能有约 1 个排队/运行任务，多推会 **429**；需串行：一本 `done` 再创建下一本。
- 书不足 60 章时会下完全部（例：47/47）。
- 下载记录/封面会写在 `book/<bookId>/`；正文 txt 在 `book/<书名>.txt`。
