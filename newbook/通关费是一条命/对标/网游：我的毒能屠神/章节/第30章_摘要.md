# 第30章 击杀黑熊王

**概要**：吴少辰战青铜BOSS黑熊王，以极速两剑上毒、裂地击飞后潜行脱战，发现中毒期间可用潜行。黑熊王追银太狼时吴少辰引仇恨带怪遛弯，十余分钟毒杀30万血BOSS。掉落2金76银、青铜2件黑铁3件及石化肌肤卷轴，换穿熊王手镯靴子护腿。濒死士兵吉瑞委托送信给城主，奖励未知，且任务进行中无法使用回城卷轴，只能跑回金陵城。

**关键事件**：1.无赖打法击杀黑熊王 2.发现中毒可潜行 3.爆装换穿三件 4.接未知奖励送信任务

**逐章写法公式**：

- **情绪流向**：起：评估Boss属性开战 → 承：裂地险死发现潜行 → 转：遛弯毒杀Boss爆装 → 合：接任务禁回城
- **节奏配比**：慢铺垫 10% / 快冲突 45% / 爽点爆发 35% / 悬念留白 10%
- **本章结构公式**：Boss属性评估 + 机制战 + 战利品 + 任务钩子
- **本章核心技巧**：Boss战先险后爽，新机制（中毒潜行）翻倍无赖感，章尾任务禁回城留悬念。
- **章尾卡点**：任务进行中无法使用回城卷轴，只能跑回城。
- **伏笔/悬念**：送信城主奖励未知；士兵死亡或触发隐藏线；非首爆掉率低。
