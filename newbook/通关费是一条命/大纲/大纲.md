# 大纲

## 全书体量与阶段总览

- 全书总章节数：约 900–1200 章（按 250–350 万字、章均约 2500–3000 字估）
- 目标字数：300 万字（区间 250–350）
- 全书情绪曲线：规则震惊 → 精算优越 → 黑市加压 → 身份掉马 → 发行权对决 → 余命兑付收束

### 阶段划分
1. 开篇期（约第 1–120 章，约 10%）：立假游戏真死、付现复活、付命通关；埋独活额度异常；情绪基调：震惊/精算爽
2. 发展期（约第 121–720 章，约 55%）：黑市庄博弈、权限分层、公会围猎、官方入场前夜；间歇兑现余命小兑
3. 高潮期（约第 721–1020 章，约 25%）：独活岁月揭示、余命大兑、发行权冲突
4. 收尾期（约第 1021–1100 章，约 8%）：规则解释权落定、账本边界、余韵

### 各阶段节奏公式
- 开篇期：每 2–3 章一次计价结算；禁止世界观长讲；禁揭独活年岁
- 发展期：小循环「目标→报价→支付→反应层→新欠单」；庄家抽水升级
- 高潮期：余命可兑开大；准备过程闪回可控剂量
- 收尾期：回收发行权与账本上限；不新开无限透支

### 关键节点与钩子链
- 关键转折：第一次付现复活；第一次付命通关；庄家逼亮家底；独活半露；官方入场
- 小/中/大高潮：小=单笔结算打脸；中=通关窗口抢命；大=余命兑付翻盘
- 阶段钩子链：开篇欠单 → 发展期谁在收通关费 → 高潮期她活了多久

## 卷级大纲

### 第一卷：入场即标价（约 8–10 万字，约第 1–30 章）
- 功能：立规则、立金手指缺口、立对手与黑市窗
- 所属阶段：开篇期
- 卷契约：付现复活成立 + 付命通关成立 + 有人开始打听「她哪来的命」
- 终局储备：主推「命价支付能力」线；禁碰独活年岁数字、发行权真身
- 核心事件：陆昭重生入场 → 第一次死后付现复活 → 第一次关键通关付命 → 与顾衡/周晏结梁子 → 黑市庄代理人盯上
- 起始状态 → 结束状态：装普通玩家的她 → 黑市挂上号的异常支付户

### 第二卷：暗盘抽水（约第 31–90 章）
- 功能：黑市深度、权限分层、额度危机
- 核心事件：庄家逼仓；余命小兑初试；周晏合作裂痕

### 第三卷及以后
- 发展期展开公会围猎与地图升级；中后期再开「余命可兑」大章与独活揭示；最终卷对发行权
