# 题材正文提示卡（《通关费是一条命》）

## 题材边界
游戏异界壳 + 命价市场。写「谁付钱/付命、付多少、换到什么、谁因此少了什么」。战斗是结算镜头，不是日常打怪流水。

## 核心逻辑
- 通关、复活、权限均可标价。
- 陆昭的优势是余命库存与定价判断，不是开局战力天花板。
- 读者要看见账：付出现金/余命/别人的死期 → 立刻有可见收益或可见坑。

## 读者期待
冷算账优越感、规则打脸（打「免费幻觉」不打路人嘴炮）、资源滚雪球、身份掉马甲的长钩。

## 核心爽点/情绪
付现复活成立；付命通关成立；转嫁成功；黑市报价打脸装杯者；后期余命大兑付。

## 正文落点
- 开场：入口临场 / 死亡瞬间 / 账单弹出 / 黑市报价。
- 冲突：付不起、谁该付、假免费、额度见底。
- 结尾：差额、欠单、下一笔通关费预告、有人开始打听「她哪来的命」。

## 前中后期打法
- 前期：立付现复活 + 付命通关；陆昭小额度精打细算；周晏/顾衡反应层。
- 中期：黑市庄抽水、权限分层、公会围猎她的「异常支付能力」。
- 后期：余命可兑开大；独活岁月准备过程揭晓；对发行权谈判/翻盘。

## 节奏密度
每 2–3 章一次可见计价或结算；禁止连续三章只聊设定不付钱。

## 场景颗粒
复活账单、通关契印章、余命余额（她可见他人约价）、黑市挂单、冷却倒计时、权限通行证、尸检式入场登记。

## 禁止漂移
- 禁止退化成纯升级打怪文。
- 禁止无脑路人嘲讽打脸当主爽点。
- 禁止开篇揭穿独活岁月全貌或发无限余命。
- 禁止官方一出场就没收她的账本。
- 面板/系统提示只保留影响胜负与标价的部分，不堆表。
