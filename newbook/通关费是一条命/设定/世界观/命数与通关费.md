# 命数与通关费

## 硬规则
1. **真死**：异界内死亡会扣除命数/余命，不是单纯读条回城。
2. **复活付现**：复活必须支付——现金等价物、抵押物、或余命额度。不存在长期稳定的「免费复活」。
3. **通关费是一条命**：关键通关节点（首通、门禁、权限跃迁）结算时必须消耗「一条命」等价物；可由通关者自付、购买他人死期、或契约转嫁。
4. **余命可兑**（中后期全面展开）：余命可兑换进度、情报、通行证；汇率随区域与庄家抽水浮动。

## 陆昭特例（金手指边界）
- **独活岁月 → 额度**：她曾独自活过极长时间；可支取的重生/复活购买力与这段「活着的时间」挂钩。
- 开篇只展示「她莫名付得起」；**准备过程与年岁数字**属后期卖点，禁止前十章说破。
- 额度有限，可透支但留后遗（缩短再囤能力 / 暴露异常支付）。

## 读者可见标价原则
正文出现死亡、复活、通关时，至少给一次可感知的价钱或差额（数字、抵押物、少了谁的命），避免空喊「很贵」。
