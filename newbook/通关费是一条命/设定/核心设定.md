# 核心设定表

### 基本信息
- 书名：通关费是一条命
- 书名卖点分配：
  - 前期卖点：《第一次复活要付现》——黄金三章立「死能结算、复活要付钱/付命」；第一次死后发现免费复活是谎言
  - 后期卖点：《余命可兑》——余命可兑换进度/权限/情报；中后段揭开女主「独活岁月＝可购买重生额度」的储备真相
  - 贯穿卖点：《通关费是一条命》——每个关键通关节点都要一条命（自己的、买来的、或转嫁出去的）
- 题材/类型：游戏异界 + 重生资源博弈（非纯数值横推）
- 目标平台：起点（选题1主投；章内节奏可学番茄短反馈，但不改付费盘定位）
- 预计字数：250–350 万字
- 目标读者：起点男频/接受女主冷算账的付费读者；要硬设定、要中后期格局
- 读者契约：看女主用「命价」精算通关与翻盘；战斗是结算，不是日常肝本流水
- 主角高光/代理权：定价权与兑换选择——谁死、值多少、用哪一笔余命买哪一次机会，必须由她判断
- 核心期待债：开篇承诺「这游戏里死了是真的，而且能标价」；首卷内兑现第一次付现复活 + 第一次用命价通关

### 一句话梗概
女主陆昭带着「独活岁月攒下的余命额度」重生回游戏异界开局前，表面像普通玩家，实则用命价买卖通关权；别人以为在打本，她在做死亡生意，直到全城发现通关费从来都是一条命。

### 主角设定
- 姓名：陆昭
- 年龄：对外二十出头；真实独活年岁远超常人（后期揭示）
- 核心特质：冷静精算、寡言、对「温情」过敏但不是无脑残忍
- 金手指/核心能力：
  1. **余命账本**：独活越久，可支取的「活着时间」越多，可购买重生/复活/关键权限
  2. **命价眼**：能看见他人剩余命数的大致标价与缺口（精度随升级台阶提升）
  3. **通关契**：关键节点可支付「一条命」完成结算（可用自己余命、买来的死期、或让对方付命）
- 弱点/缺陷：额度有限且不可无限透支；过度支取会缩短「可再独活/可再囤」的未来；人情债与定价冷静冲突时易误判
- 核心动机：不为情怀闯关——她要买回对死亡规则的解释权，并还清上一世独活时欠下的那笔「必须回来」的账（具体对象首卷只露钩，不提前揭底）

### 世界观骨架
- 时代/背景：近未来都市外壳 + 突然开放的「游戏异界」入口；大众当网游，内层按命数结算
- 核心设定：通关、复活、区域权限均可标价；硬通货不是金币，是**命/余命/死期窗口**
- 力量体系：表层战力等级 + 里层命价权限（情报/通行证/复活冷却）；战力可输，没命价寸步难行
- 社会结构：玩家公会、黑市掮客、官方特事口（后期入场）；黑市先于官方成熟

### 核心冲突
- 主线矛盾：陆昭要用有限余命额度通关并囤权，对上「免费通关幻觉」培养出的既得利益者与真·吃命规则的幕后盘
- 终极 Boss/终极阻碍：掌握「命价发行权」的一方（人或规则本身）——禁止开篇点名；首卷只碰到代理人/黑市庄家

### 开篇三章义务（对应书名卖点）
1. 立「假游戏」入口误解
2. 第一次死亡 → **复活要付现**（钱/抵押/余命任选其一落地，必须当场计价）
3. 第一次关键节点 → **通关费是一条命**（付出去，看得见谁少了什么）
