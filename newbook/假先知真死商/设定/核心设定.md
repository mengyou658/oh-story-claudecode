# 核心设定表

### 基本信息
- 书名：假先知，真死商
- 书名卖点分配：
  - 前期卖点：命数黑市（伪装先知算命）——黄金三章主兑现：用「算命」壳子做命数情报交易
  - 后期卖点：这本不许复活——中后段揭穿世界硬规则：死亡不可回档，所有「复活」都是骗局或代价陷阱
  - 贯穿卖点：我拿死亡做生意——全书主线：把死亡额度/死契/命数残片做成可交易硬通货
- 题材/类型：游戏异界 + 重生脑洞（女主） / 资源博弈
- 目标平台：番茄（主）／起点可改节奏另开壳
- 预计字数：180–250 万字
- 目标读者：爱重生爽感、接受硬规则、喜欢「演戏信息差 + 资源变现」的番茄读者；不排斥女主冷算账
- 读者契约：看女主用死亡做生意碾过信息差市场；假先知壳子不断掉马又补壳；最终揭穿「不许复活」时读者要感到爽+震撼，不是纯虐
- 主角高光/代理权：只有她敢给死亡标价、敢用「赴死」当筹码；关键布局/定价/拒单都由她拍板
- 核心期待债：开篇立下「队友全死、她想赴死却重生」→ 必须在前中期兑现「用死亡做生意」的第一笔成单；全书须偿还「队友为何死、为何不许复活」

### 一句话梗概
巅峰清图后队友尽死、独守空城几十年的女主赴死未成却重生回入场前夜——她伪装先知开命数黑市，专卖别人不敢碰的死亡生意，直到揭开「这本不许复活」的世界底牌。

### 主角设定
- 姓名：沈烬
- 年龄：重生时 22；前世心理年龄约 60+
- 核心特质：冷账本思维、对「活着」过敏、护短（只护已死者的名分）
- 金手指/核心能力：
  1. 前世完整「命数层」经验（先知信息差）
  2. 【死契账本】——可登记、拆分、交易「死亡额度／死契残片」（别人不敢用的唯一资源）
  3. 假先知外壳：对外是算命摊/灵媒，对内是黑市庄家
- 弱点/缺陷：对活人信任阈值极高；容易把「能活下去的人」当成潜在炮灰；情绪钝化后偶发失温，差点错过关键盟友
- 核心动机：前世赴死是为陪队友；今生「做死亡生意」是为把死有所值——查清队友为何必须死、谁在贩卖假复活、怎样让后来者不必再站在空城上看风景几十年

### 世界观骨架
- 时代/背景：近未来都市 + 「命数副本」公开化（大众以为是沉浸式高危游戏）
- 核心设定：入场以为打本，实则命数层真死；死亡可被登记成额度进入黑市；官方与世家把「假复活」当维稳叙事
- 力量体系：命数权限（窥/改/锁/卖）四级；战斗力是结算手段，不是日常刷怪主轴
- 社会结构：表层——游戏公司/公会/直播生态；里层——命数管理局、世家命仓、黑市庄家三方博弈

### 核心冲突
- 主线矛盾：谁有权给死亡定价？沈烬要开透明（对她而言）的命数黑市，撼动官方假复活叙事
- 终极 Boss/终极阻碍：「复活产业」幕后庄家（把队友送去死、再卖假希望的那套制度）+ 世界硬规则「不许真复活」本身

### 前世锚点（开篇必用）
- 站在世界之巅，队友全死，独看风景几十年 → 决定赴死 → 睁眼重生
- 前世空城画面作为情绪发动机，禁止开篇灌设定；用动作与账单感带出

### 对标迁移（主对标《游戏入侵》）
- 借：重生信息差、稀缺资源变现、当面演戏/暗处搞事、官方谈判抬天花板
- 不借：女主半杀亲族流水账、盗神/食神专名、具体内测钟点桥段
- 换壳：截胡对象从「弟弟机缘」改为「第一笔死契单 / 假复活掮客」；清家改为「清假先知同行的假命仓」
