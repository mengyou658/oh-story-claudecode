# 细纲（第 1 章）

### 第 1 章：你们等等我
- 核心事件：巅峰后独守海景房几十年的沈烬向队友照片道早安并赴死，睁眼重生回入场前夜
- 字数目标：2200 字
- 字数口径：visible_chars_v1
- 阶段位置：开篇期；第1阶段第1章；立人设与情绪债
- 单元ID/位置：L1-01；建立期待
- 目标情绪：孤冷绝望 → 骤然清醒的错位紧张；推进「她不是普通人开局」的认知
- 主角目标/关键选择：选择赴死；重生后第一反应是确认「还要不要死」
- 章节定位：高压
- 本章结构公式：照片早安仪式（立执念） + 赴死动作（兑现） + 睁眼错位（反转） + 时间戳落地（钩子）
- 章首钩子：悬念对话/反差场景 — 对着已故队友照片逐个说「早啊」；笑容是擦出来的
- 爽点：无显性爽点，功能是立队友债与赴死动机；期待点=她睁眼了
- 本章标价：几十年独守 = 「活着的税」；赴死 = 她付清这笔税的尝试。尺子在道别前立好
- 闭环状态：下注在「赴死能否陪队友」；开奖为失败（重生）；获得拍在睁眼，估值暂负
- 本章禁止提前释放：死契账本细节；命数黑市；不许复活法理；顾衡
- 写手自由区：照片里队友怎么称呼、笑容怎么假、赴死方式怎么干脆
- 契约风险：契约安全

#### 内容概括（五段式）
- 起因：队友尽死，她独守海景房太久
- 发展：她完成「对照片道早安→看海」的固定仪式，决定随他们去
- 转折：死未成，感官回到年轻身体
- 高潮：确认重生——时间戳砸下来
- 结尾：她盯着旧房间，没哭，只说「又来。」

#### 情节安排（多线）
- 主线推进：立队友债与重生前提
- 辅线推进：无
- 事件线 / 任务线：早安仪式→赴死→失败→重生确认
- 任务卡点：无

- 逻辑线：独守过久 → 赴死 → 被甩回原点 → 新问题：还活着

#### 人物关系和出场顺序
- 出场顺序：沈烬；队友仅以照片/称呼存在（不现身）
