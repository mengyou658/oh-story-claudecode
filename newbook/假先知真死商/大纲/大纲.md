# 大纲

## 全书体量与阶段总览

- 全书总章节数：约 700 章（番茄短章节奏；可按追读微调）
- 目标字数：约 200 万字
- 全书情绪曲线：空城孤冷 → 重生冷算 → 黑市滚雪球 → 假复活撕裂 → 规则震撼（不许复活）→ 空城意义改写

### 阶段划分
1. 开篇期（第 1–80 章，约 10%–12%）：立人设（赴死→重生→假先知）、立金手指（死契账本）、立市场（命数黑市首单）；情绪基调：孤冷→冷爽；结束时读者认同沈烬定价权并期待砸假同行
2. 发展期（第 81–420 章，约 50%–55%）：清假命仓、扩城盘、管理局博弈、队友死因线索；情绪：期待/紧张/间歇成交爽；结束时迫切想揭「不许复活」
3. 高潮期（第 421–630 章，约 25%–30%）：复活产业对决、规则源揭露、空城再现；情绪：爽感/震撼；核心矛盾进入终局
4. 收尾期（第 631–700 章，约 8%–10%）：假复活产业链清算、名册落定、余韵；情绪：释然/冷暖交织

### 各阶段节奏公式
- 开篇期：立壳首单 / 孤冷转冷爽 / 高密度成交与砸场 / 埋队友名册与假复活传单 / 冲突在摊位-街区级 / 钩向清同行 / 禁止全文法「不许复活」
- 发展期：扩盘博弈 / 紧张期待 / 中密度 / 分批放队友死因 / 冲突升至城-管理局 / 钩向规则源 / 禁止打光账本改官方登记
- 高潮期：规则对撞 / 震撼爽 / 连续兑现 / 回收空城 / 冲突至真庄家 / 钩向收束 / 禁止无代价真复活
- 收尾期：清算余韵 / 释然 / 低密度收线 / 必须回收名册与黑市去向

### 关键节点与钩子链
- 关键转折点：第 5 章首单；约第 40 章清柳望舒假命仓；约第 80 章管理局正式谈价；约第 200 章空城坐标再现；约第 450 章「不许复活」揭牌
- 小/中/大高潮：小高潮第 5/15/40 章级；中高潮第 80/200 章级；大高潮「不许复活」揭牌与真庄家对决
- 阶段钩子链：开篇末→清城盘；发展末→规则源；高潮末→名册与余生选择

## 卷级大纲

### 第一卷：假摊真账（约 15 万字，约 60 章）
- 功能：起步 / 第一个大爽点（首单+砸同行）
- 所属阶段：开篇期为主，卷末接入发展期入口
- 卷契约：兑现「命数黑市伪装先知」；看见「我拿死亡做生意」成单；埋「假复活」线，不揭穿「不许复活」全文法
- 终局储备：主推资源线（黑市定价权）；战果含信息线（队友名册闪回）、人脉线（顾衡）；禁碰真庄家身份与不许复活法理全文
- 剧情单元：L1-01 重生立壳首单；L1-02 砸场清假命仓；L1-03 管理局眼线与扩盘（详见卷纲）
- 阶段边界：可释放死契基础规则与假先知壳；禁止提前释放规则源/真复活判定全文
- 核心事件：空城赴死重生 → 开假摊 → 首单死契 → 清柳望舒 → 周晏上门谈价
- 起始状态 → 结束状态：想死的幸存者 → 一城暗盘庄家雏形（仍拒被收编）

### 第二卷及以后（鸟瞰）
- 第二卷：城盘与世家命仓（扩卖、假复活中介链）
- 第三卷：空城坐标与队友死因（信息线主推）
- 第四卷：复活会对撞（后期卖点加压）
- 第五卷：不许复活揭牌 + 真庄家
- 最终卷：名册落定与黑市去留
