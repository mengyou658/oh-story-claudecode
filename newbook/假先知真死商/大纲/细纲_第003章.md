# 细纲（第 3 章）

### 第 3 章：要买死一次的人
- 核心事件：沈烬支起假算命摊，顾衡上门只要「死一次」的资格
- 字数目标：2300 字
- 字数口径：visible_chars_v1
- 阶段位置：开篇期；金手指将亮未亮；前期卖点「命数黑市」入口
- 单元ID/位置：L1-01；尝试
- 目标情绪：日常装神弄鬼的轻嘲 → 询价骤冷的紧张；读者感到「第一单来了」
- 主角目标/关键选择：判断顾衡是真需求还是试探；选择不赶客、先询价
- 章节定位：推进
- 本章结构公式：支摊立壳 + 普通客人对比 + 顾衡异询价 + 她收下定金式信物
- 章首钩子：场景反差 — 巅峰幸存者在巷口摇签
- 爽点：信息差优越（她听懂「死一次」而旁人当玩笑）
- 本章标价：普通算命=几张票；「死一次」=命数成。尺子在对比客人时立好
- 闭环状态：下注在点末；第4章开奖（能否真接下死契）
- 本章禁止提前释放：账本具现细节；管理局；柳望舒可仅传闻
- 写手自由区：摊位对话怎么像神棍、顾衡怎么不像来算姻缘的
- 契约风险：契约安全

#### 内容概括（五段式）
- 起因：她按计划支摊获客
- 发展：打发两三个无聊客人，立「假先知」壳
- 转折：顾衡开口只要死一次
- 高潮：她报价试探，双方互相打量
- 结尾：她收下他的信物/订金，约「验货」

#### 情节安排（多线）
- 主线推进：L01 出现第一笔潜在死契单
- 辅线推进：L02 从零到询价
- 事件线 / 任务线：支摊→异询价→收订
- 任务卡点：无
- 感情线 / 关系线：无显性；沈烬-顾衡利益试探开始
- 逻辑线：壳子吸引眼球 → 真需求撞上 → 进入验单流程

#### 人物关系和出场顺序
- 出场顺序：沈烬 → 路人客 → 顾衡
- 镜头准入：沈烬/顾衡台词位；路人可合并
- 人物关系变化：陌生 → 买卖双方互疑
- 视角/信息差：读者知她真懂死亡；顾衡不知她前世
- 信息差触发点：路人笑「谁买死啊」时，她与顾衡都没笑
