# 第1章 你们等等我

早啊。

你也早。

你也早。

沈烬对着墙上的照片一个个打招呼，阿棠、老七、小满、渡，嘴角往上抬两毫米，再用指腹把那点笑意擦亮，像给玻璃抛光。她做这套动作做了几十年，早就做成了固定工序，问好、上屋顶、看海、下楼、活着，活着的利息按日计，计到海在她眼里只剩一条线。

她走上屋顶，阳光海滩的海景房，浪声旧，风咸。她把每天该看的那一份看完，阿棠那张照片边角又翘起来，她昨天花了十分钟压平，今天照样翘，她懒得再管。

今天多一步。

「我也该走了，你们等等我。」

沈烬翻过栏杆。

风灌进耳朵，视野里海面倒转，阳光刺白，她没有闭眼，她想把最后一眼留给海，也留给那些不会再应声的人。

她睁开眼。

天花板廉价，灯罩积灰。她下意识鲤鱼打挺坐起，腰腹一空，什么都没借上力，整个人又摔回床里，体内的反应明明白白告诉她，她现在就是个普通人，腕上那道海风磨出来的旧伤疤没了，关节里也没了锈。

枕边手机震了一下。

沈烬拿起来一看，锁屏还是出厂默认，上面显示某年3月19日，周二，上午9:17。

命数入场报名还剩最后两天。

她呼吸都急促起来。

又来。

她翻身下床，先去洗手间泼了把冷水，镜子里的脸嫩得刺眼，眼睛却老。她对着镜子又说了一遍「早啊」，没人应。点开热搜，第一条挂着官方文案：失败可重来，死亡可重启，勇敢进本。短视频里有人举着头盔笑，弹幕刷死后满血，有人问什么时候公测，官方账号回了个加油表情。

骗子。

骗子！！

可是下一秒，她自己都为自己的冷静感到吃惊。再赴死一次很容易，窗户就在那儿，四楼，水泥地，摔下去大概够干净。可她盯着那四个字，忽然觉得这笔账不解气。他们死得干干净净，有人却还在卖重来的希望。她前世站在世界之巅时队友一个不剩，今生若再白死一次，不过是给骗子广告多送一份流量。

没有必要再死一次。

没有意义！

她只需要把死亡标上价。

沈烬拉开抽屉，摸出空白便签，写下：死亡，标价。笔尖顿住，她补一行：先做生意。再补一行：假先知壳。获客。筛单。上辈子那些装神弄鬼的摊位她见得多，签筒、香灰、半真半假的签文，够挡住眼睛，也够把真正要买死的人筛出来。

她套上外套出门，在旧货市场转了两小时，淘到一只缺角签筒、半盒潮香、三本撕了封面的旧书。老板问她算什么，她道：「算别人怕什么。」老板当她开玩笑，多塞了两根断香。

当晚她把道具摊在床上，一件件擦干净，动作熟得像从前擦照片上的灰。她对着空墙试了两遍「早啊」，声音发干，自己先停了。睡了四个小时，睡得很死，赴死的惯性被她按进枕头里，暂不执行。客从哪来，壳能不能挡住人，第一单会不会是试探，这些问题她睡着前都过了一遍，一个都没答案。

巷口支摊那天，日头毒。

帆布袋往地上一搁，签筒摆正，香点着。第一个客人问姻缘，沈烬头也不抬，道：「姻缘凶。改日再来。」对方骂了句神棍走了，她照收那半句骂，当开张彩头。

第二个问财运。她摇出三支签，收了两张票，话术半真半假：哪个月忌投资，哪条路别走夜路，够把人打发走，不够让人记住她的脸。围观的人笑她装神弄鬼，她也笑，笑得很职业，嘴角那两毫米又回来了。有人问准不准，她道：「准不准，看你怕不怕。」

第三个坐下时，笑声短了一截。

男人三十上下，衬衫扣到最上一颗，袖口干净，眼睛却不像来算姻缘的。他把一块旧铜牌推过桌面，铜牌边缘磨得发亮，像被许多人摸过，又像只被一个人摸了很久。

「我要买死一次的资格。」他道。

旁边有人哄笑：「谁买死啊？大不了重来呗。」

沈烬没笑。对面那人也没笑。

她抬眼看他，指尖在签筒边停了一停，像摸到一只还没显形的账本边角，痒了一下。巷口的笑声还在，她听得很清楚：这些人把死当成游戏里的一次读档。

好好好。

「死一次。」她报了价，数字刺耳，「三成命数，预付一成。赊账免谈。假复活，不做。」

男人眉心跳了一下，道：「你懂？」

「验货。」沈烬收下铜牌，把它按进抽屉最深处，盖上一本撕了封面的旧书，「今晚旧厂后巷。带齐你的诚意。缺一成，单子撕。多问一句来历，单子也撕。到了只验货，不讲故事。」

「三成很贵。」

「死一次本来就贵。」她道，「你要便宜的，对面广告栏有，写着死后满血。」

顾衡沉默两秒，忽然问：「你自己死过吗？」

沈烬：“” 问得好。可她不会答。

「验货见。」她把签筒转开，挡住他的视线，「现在，起价已报。走或不走。」

他盯着她看了两秒。巷口油烟翻上来，有人在喊豆浆，围观的人散了大半，只剩一个大爷还在远处抽烟假装看热闹。

「记账用。」沈烬道。

「顾衡。」

他点头，起身走了，脚步稳，不像来闹事的。铜牌离开桌面后留了个浅印，很快被热风吹干。沈烬等他拐过街角，才把香掐灭半截，省着用。

阳光照在空荡荡的墙影上，像海景房顶那些照不回来的脸。她在便签背面多写了一笔：顾衡。要死一次的人。验货。旧厂后巷。问过我死没死。不答。

抽屉里铜牌轻轻一响。香灰落下一小截，她用鞋底碾灭。她收起笑容，低声说了一句只有自己听见的话。

「等等我。这回，我先去把死亡标上价。」

可旧厂那边会验出什么，她自己也还没完全有数。
