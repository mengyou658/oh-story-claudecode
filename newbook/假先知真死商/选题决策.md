# 选题决策：游戏题材 · 跨平台
- 扫榜日期：20260914
- 数据来源：起点游戏月票/畅销/签约新书/新人签约；番茄男频游戏体育阅读榜/新书榜（见同目录榜单文件）

## 推荐选题

### 选题 1：游戏异界 ·「假游戏真死」+ 可交易的唯一资源
- 题材组合：游戏异界 + 生存资源博弈（非纯数值横推）
- 目标读者：起点男频，接受硬设定、要中后期格局的付费读者
- 核心卖点：入场以为打本，实则命数/真相层翻盘；主角握有「别人不敢用」的交换物
- 能爆的原因：月票/畅销上《浊世游戏》《异维囚笼》《升格耀变体》重复证明「游戏皮 + 真实生死 + 异界沉浸」仍吃付费盘；用资源博弈替代纯战力榜，降低琥珀流硬跟风险（假设，`待拆文验证`）
- 差异化定位：不做机械师面板复刻；主线是情报/命数/权限市场，战斗是结算不是日常
- 可行性：中 — 同方向起点样本 ≥15 且趋势→，但琥珀/异界跟风多；作者需能撑世界观。样本够故可写，差异化未拆文坐实前不给「高」
- 失败风险：中期变成普通升级文；真相揭太早或太晚；和《浊世》《惊悚乐园》气场撞车
- 验证动作：先写黄金三章（入场误解→第一次「真死」代价→资源交易钩子），看首订/追读再开长线
- 篇幅/平台：200–400 万字级；**主投起点**，番茄可改节奏另开短连载壳但不建议同一稿双投

### 选题 2：番茄向 · 热游电竞直播（三角洲/无畏）+ 技术碾压日常
- 题材组合：电子竞技 + 直播吐槽 + 单女主或无女主
- 目标读者：番茄男频，玩过或围观过该游戏的流量读者
- 核心卖点：名场面复盘快感 + 直播弹幕情绪；低门槛（简介声称「没玩过也能看」可作保险）
- 能爆的原因：番茄阅读/新书榜多次出现三角洲、无畏契约、CS2；与起点 LOL 图文流形成平台错位，追的是**当下热游**而非峡谷怀旧（假设，`待拆文验证`）
- 差异化定位：避开起点 LOL 红海；主视角用「退役/雪藏天才回归直播」而非又一遍世界赛夺冠流水账；章节短、爽点密
- 可行性：中 — 番茄游戏体育样本充足，但热游窗口短，IP 热度掉则流量掉
- 失败风险：游戏版本改动导致设定过期；纯技术描写劝退；与直播录播无差异
- 验证动作：先更 30–50 章测完读与在读；选题绑「仍在爆发的赛事/版本」
- 篇幅/平台：**主投番茄**；80–200 万字快节奏；不指望起点月票盘

### 选题 3：双平台可改编壳 ·「游戏制作人」做小众硬核坑 + 玩家生态反噬
- 题材组合：游戏系统/游戏制作 + 玩家群像（第四天灾变体）
- 目标读者：起点偏制作/厂牌向付费读者；改标签堆叠后可试番茄
- 核心卖点：主角做「小众变态难游」，筛玩家；玩家攻略、出bug、出圈反噬制作组
- 能爆的原因：起点月票有《美利坚：游戏制作教父》，新人签约 #1《你赢了，你的游戏小众又变态》；签约新书有「光明神做游戏赚信仰」——制作向正在形成重复样本（假设，`待拆文验证`）
- 差异化定位：不做编年史厂牌文；聚焦「一款游戏从0到1」的版本迭代与玩家斗法，单作闭环感强
- 可行性：中 — 新书信号强于畅销厚度；制作向素材（版本设计、社区）要求高
- 失败风险：变成游戏设计说明书；玩家群像失控；番茄读者觉得慢
- 验证动作：大纲只规划「一款游戏三个大版本」；首卷只写内测→公测翻车→第一个出圈事件
- 篇幅/平台：起点 150–300 万；若改番茄需砍设定、加玩家翻车名场面密度
