## 全书体量与阶段总览

- 全书总章节数：约 450–600 章（番茄短章快更）；细纲滚动规划
- 目标字数：120–180 万字
- 全书情绪曲线：独活余味 → 跳月上场 → 被迫应战短结算 → 前世回忆加压 → 寿命暗抽的心虚优越 → 运渐显 → 规则被挖出的公共危机 → 花命救秦小源的中点 → 终局对规则源头；游戏目的多猜想并置

### 道德前提与大两难

- **道德前提**：把人当耗材、逼人当先锋是错的；把命只花在自己认的账上才对。——躺平不是逃责，是拒绝被世界当燃料。
- **大两难①（约第 55–60 章 / 开篇期末）**：公开亮牌护周晏 vs 继续匿名私下结清。选定：护闺蜜可破例、仍拒当先锋。陆昭不进场。
- **大两难②（约第 220–240 章 / 救英雄中点）**：掏寿命救秦小源 vs 袖手保库存陪周晏。选定：第一次主动花命救秦，只谈交换。贺予川另线。
- **大两难③（约第 360–380 章 / 高潮前）**：交出局部价码换筹码 vs 捂死独自对源头。选定：暗账合伙人，结算权自持。

### 隐藏贯穿题（不算两难）

**游戏的目的是什么？** 前世通关后只剩她一人，然后是漫长独活。全书多次留下猜想，**不给唯一官方答案**：
1. 世界想让她重来
2. 通关是把「最后一个人」炼成钥匙/燃料
3. 游戏在收割寿命与运，通关者是最优质长期账户
4. 独活是惩罚：薅光机缘却结不清「人」的账
5. 上位存在在等一个愿意再次花命的人——她是候选人不是赢家
6. 没有目的，规则自转；意义是她事后贴上的

### 开篇硬结构

1. 海景屋顶：对独活失去之人的照片问好 → 勉强笑 →「不是因为开心才笑…」→ 望海 →「你们等等我」
2. **一个月后……** 跳入重生现实；月内准备遇事倒铺
3. 陆昭=小丑：无视或私下断关键资源；禁止开局呼晕主冲突

### 关键人物钉

- 秦小源：湮灭挡灾；两难②优先救；约正文第30章后闪回（细纲约第90章前后，补纲校准）

### 阶段划分
1. 开篇期（约 10%，细纲 1–60）：照片+跳月、躺平、入侵、私下结清；寿命只埋毛边；两难①
2. 发展期（约 55%，细纲 61–280）：暗抽寿命、顾衡大回忆、特事局、世人挖寿命、枯竭潮、闪回、救秦（两难②）、运渐显、贺予川叉
3. 高潮期（约 25%，细纲 281–400+）：源头、价码、两难③、猜想轮换
4. 收尾期（约 10%，细纲 400 之后）：源头结算、独活真相收束、陪闺蜜；游戏目的不唯一揭晓

### 各阶段节奏公式
- 开篇期：立人设+满级橱窗 / 冷爽 / 每 2–3 章一小结算 / 寿命只埋毛边 / 陆昭≤小丑插曲 / 禁寿命抽离与运点名与价码
- 发展期：暗账扩容+官方杀价 / 紧张间歇爽 / 前世加压 / 升至世家与特事局 / 禁提前救英雄终局化与源头对决
- 高潮期：公共危机+花命 / 震撼 / 连续中高潮 / 至规则源头
- 收尾期：源头结算+日常余韵 / 释然 / 回收：价码、寿命库存、运、闺蜜羁绊；猜想并置

### 关键节点与钩子链
- 关键转折：开篇照片跳月；首次窗口清障；盯梢私下结清；首次实抽寿命；**约正文第30章后战友闪回（卷2）**；花命救秦（卷3）；价码交易
- 小/中/大高潮：小=窗口清障/盯梢结清；中=实抽/闪回/特事局杀价/救秦；大=源头战
- 阶段钩：开篇末「身边有人」→ 暗抽与闪回与官方接口 → 规则被挖与运假说 → 源头结算
