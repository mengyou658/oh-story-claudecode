# 全书大纲

## 全书体量与阶段总览

- 全书总章节数：约 450–600 章（番茄短章快更）；细纲当前规划至第 400 章（未完本）
- 目标字数：120–180 万字
- 全书情绪曲线：退休确认的冷爽 → 被迫应战的短结算 → 前世回忆加压 → 命数暗抽的心虚优越 → 规则被挖出的公共危机 → 花命救一人的中点 → 终局对规则源头（400 章停在终局对决前夜）

### 阶段划分
1. 开篇期（约 10%，细纲 1–60）：立躺平规矩、满级橱窗、游戏入侵、第一次私下结清；命数只埋毛边
2. 发展期（约 55%，细纲 61–280）：暗抽命数、前世顾衡大回忆、特事局间接口、世人挖命数、枯竭潮、用命救英雄
3. 高潮期（约 25%，细纲 281–400+）：逼近规则源头、寿命价码局部揭晓、抬价交易；全书终局可续至 450–600
4. 收尾期（约 10%，细纲 400 之后）：规则源头结算、独活真相收束、陪闺蜜把日子过完
