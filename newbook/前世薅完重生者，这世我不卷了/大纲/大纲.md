# 全书大纲

## 全书体量与阶段总览

- 全书总章节数：约 450–600 章（番茄短章快更）；细纲滚动规划，首批至第 10 章
- 目标字数：120–180 万字
- 全书情绪曲线：退休确认的冷爽 → 被迫应战的短结算 → 前世回忆加压 → 命数暗抽的心虚优越 → 规则被挖出的公共危机 → 花命救一人的中点 → 终局对规则源头

### 道德前提与冲突配额（大纲生成要求）

- **道德前提**：把人当耗材、逼人当先锋是错的；把命只花在自己认的账上才对。——故事用情节证明：躺平不是逃责，是拒绝被世界当燃料；真正该花的命，只在「认下的人」与「结清的账」上花，不许世界替她定价。
- **大两难①（约第 55–60 章 / 开篇期末）**：公开亮牌护周晏（名字响、满级暴露、躺平契约崩）vs 继续匿名私下结清（周晏继续当「幸运靶」、女主可控但欠人情债）。两边都不能无损：亮牌毁退休局，匿名则闺蜜持续承压。选择改写主线——她把「护闺蜜」定为可破例的唯一账，但仍拒当先锋。
- **大两难②（约第 220–240 章 / 发展期中点·救英雄）**：掏自己命数库存救国家英雄（公开化风险、库存见底、独活创伤复发）vs 袖手旁观保库存陪周晏（英雄死、世人枯竭潮加速、她被钉成「袖手旁观者」）。两边都不能无损：救则被动抬价进公共棋盘，不救则道德前提被世人反向审判。选择改写人物——她第一次主动花命，仍只谈交换不谈理想。
- **大两难③（约第 360–380 章 / 高潮前）**：把命数规则与寿命价码部分交出去换终局筹码（身份终点提前兑现、自由缩水）vs 把底牌捂死独自对规则源头（陪闺蜜的日常可能被烧穿、无人可托底）。两边都不能无损。选择改写终局——她成为暗账合伙人而非先锋，把「谁该死几次」的结算权捏在自己手里。
- **小冲突清单（共 20 条；自我或外部；爆发 / 升级 / 反转 / 处理）**：
  1. 自我·爆发：怀疑重生是梦，却必须立刻对陆昭表态（计划落点：第 1 章 / L1-1）
  2. 外部·处理：四下无人时收力呼晕渣男，有人走近则改避锋（计划落点：第 2–3 章 / L1-1）
  3. 外部·反转：约闺蜜躺平，周晏却想趁窗口冲一把（计划落点：第 4–5 章 / L1-1）
  4. 外部·爆发：游戏入侵公告打乱「再躺三天」计划（计划落点：第 6 章 / L1-2）
  5. 自我·升级：怕暴露满级 vs 必须给周晏截一份安稳机缘（计划落点：第 7–8 章 / L1-2）
  6. 外部·处理：窗口竞争者逼近，计划被打乱后临场改方案清障（计划落点：第 9 章 / L1-2）
  7. 外部·升级：周晏差点炫耀漏嘴，女主现场灭火（计划落点：第 10 章 / L1-2）
  8. 外部·爆发：嗅探型玩家盯上「幸运周晏」（计划落点：第 11–13 章 / L1-3）
  9. 自我·处理：想起前世某人因炫耀而死，强迫自己缩影（计划落点：第 14–15 章 / L1-3）
  10. 外部·升级：小公会「养幸运号」话术诱惑周晏（计划落点：第 16–18 章 / L1-4）
  11. 外部·反转：线下跟梢出现，原「线上灭火」方案失效（计划落点：第 19–20 章 / L1-4）
  12. 外部·爆发：登录点被堵，被迫布局无人处结清（计划落点：第 21–23 章 / L1-5）← 对应大两难①预热
  13. 自我·反转：结清后短暂松懈，命数毛边第一次刺痛（计划落点：第 24–25 章 / L1-5）
  14. 外部·升级：二次窗口拥挤，匿名送机缘反而引来「身边有人」疑云（计划落点：第 28–30 章 / L1-6）
  15. 外部·爆发：世家/公会级对手入场，小结算手段不够用（计划落点：第 45–55 章 / 卷1末）
  16. 自我·处理：第一次实抽命数后的道德余震与暴露焦虑（计划落点：第 65–75 章 / 卷2）
  17. 外部·反转：前世顾衡大回忆揭示「薅完却独活」的空（计划落点：第 90–110 章 / 卷2）
  18. 外部·升级：特事局上门要价，她杀价交易拒编制（计划落点：第 120–140 章 / 卷2）
  19. 外部·爆发：世人挖出命数规则，枯竭潮把暗账逼成公共危机（计划落点：第 160–200 章 / 卷3）
  20. 自我·处理：规则源头试压前，是否交出局部价码换筹码（计划落点：第 300–350 章 / 卷4）← 衔大两难③

### 阶段划分
1. 开篇期（约 10%，细纲 1–60）：立躺平规矩、满级橱窗、游戏入侵、第一次私下结清；命数只埋毛边；兑现大两难①预热与落点
2. 发展期（约 55%，细纲 61–280）：暗抽命数、前世顾衡大回忆、特事局间接口、世人挖命数、枯竭潮、用命救英雄（大两难②）
3. 高潮期（约 25%，细纲 281–400+）：逼近规则源头、寿命价码局部揭晓、抬价交易（大两难③）；全书终局可续至 450–600
4. 收尾期（约 10%，细纲 400 之后）：规则源头结算、独活真相收束、陪闺蜜把日子过完

### 各阶段节奏公式
- 开篇期：立人设+金手指橱窗 / 冷爽 / 每 2–3 章一小结算 / 命数只埋毛边 / 冲突停在现实摩擦与小公会 / 阶段钩=「身边有人」疑云 / 禁提前释放命数抽离与寿命价码
- 发展期：暗账扩容+官方杀价 / 紧张间歇爽 / 前世回忆加压 / 冲突升至世家与特事局 / 阶段钩=枯竭潮 / 禁提前救英雄与源头对决
- 高潮期：公共危机+花命 / 震撼 / 连续中高潮 / 冲突至规则源头 / 阶段钩=价码交易 / 禁一次性打光终局底牌
- 收尾期：源头结算+日常余韵 / 释然 / 回收伏笔 / 必须回收：寿命价码、命数库存账、闺蜜羁绊落定

### 关键节点与钩子链
- 关键转折点：第 3 章满级呼晕；第 9 章首次窗口清障；第 23 章私下结清盯梢；第 70 章前后首次实抽命数；第 230 章前后花命救英雄；第 370 章前后价码交易
- 小/中/大高潮：小高潮第 3 / 9 / 23 章；中高潮第 70 / 140 / 230 章；大高潮第 340+ / 终局卷
- 阶段钩子链：开篇末「身边有人」→ 发展期暗抽与官方接口 → 高潮期规则被挖 → 收尾期源头结算
