# 全书大纲

## 全书体量与阶段总览

- 全书总章节数：约 450–600 章（番茄短章快更）
- 目标字数：120–180 万字
- 全书情绪曲线：退休确认的冷爽 → 被迫应战的短结算 → 前世回忆加压 → 命数暗抽的心虚优越 → 规则被挖出的公共危机 → 花命救一人的中点 → 终局对规则源头

### 阶段划分
1. 开篇期（约 10%）：立躺平规矩、满级橱窗、游戏入侵、第一次私下结清；命数只埋毛边
2. 发展期（约 55%）：前世回忆穿插、暗抽命数、间接国家合作、护闺蜜；禁止揭全价码
3. 高潮期（约 25%）：命数规则被世人挖掘、枯竭潮、用命救国家英雄（中点）、被迫抬价交易
4. 收尾期（约 10%）：规则源头结算、独活真相收束、陪闺蜜把日子过完
