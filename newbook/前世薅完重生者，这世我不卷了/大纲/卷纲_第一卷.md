> 作用域：卷级常任
- 章节范围：第1-60章

## 卷契约与终局储备（参 `reader-contract-and-progression.md`）
> 作用域：卷级常任
- 卷契约：读者确认「她能打但不想打」；闺蜜锚立住；跳月后第一次私下结清兑现期待债
- 本卷主推线：信息线（独活余味+满级+躺平规矩+入侵窗口）
- 本卷战果：关系线（周晏）、资源线（月内倒铺的物资/登录位）、小公会盯梢结清；陆昭仅小丑插曲
- 本卷解锁的终局里程碑：无大底牌；仅确认「她已付过重生价」的存在感（不揭价码）
- 本卷禁碰的终局底牌：寿命买重生全貌；寿命抽离公开；运点名；救英雄；规则源头；女主主动当先锋；游戏目的唯一解
- 本卷鼓励长出的：闺蜜小目标、登录窗口细则、小公会压力（不作嘲讽流水线）、顾衡短闪回、月内准备倒铺
- 契约风险：契约安全——国家线本卷最多远景钩；陆昭不进大两难
- 本卷冲突索引：C01–C22（见 `大纲/大纲.md`）
- 本卷大两难：①（约55–60）亮牌护周晏 vs 匿名结清 → 破例护闺蜜、拒先锋

## 全卷常任裁定
> 作用域：卷级常任

1. 周围有人 → 避锋芒；周围无人 → 一次结清；国家线 → 只谈交换（本卷最多远景）；陆昭 → 无视或私下断链。
2. 每章剧情闭环：短计划 → 突发打乱 → 临场改方案 → 心理闪念复盘（禁清单式复盘）。
3. 禁止无脑路人嘲讽打脸；禁止开篇大段设定说明；寿命只埋毛边不实抽；运不点名。
4. 前世回忆只允许与当下强相关的碎片；禁止大段完整闪回（本卷）。
5. 开篇禁止写满一个月流水账；准备遇事倒铺。
6. 文风：冷短干净；客观叙事为主，内心后置。

### 剧情单元 L1-1
> 作用域：单元级 L1-1
- 单元ID：L1-1
- 章节范围：第1-5章
- 对标剧情参照：自创开篇情绪橱窗；借对标「先兑现再缺口」的结构，**换素材**为照片/跳月/满级确认，不借呼晕渣男主冲突
- 单元节拍/章功能分配：照片问好+望海1 → 跳月切入+月内毛边2 → 满级确认+躺平规矩3 → 接上周晏/陆昭小丑插曲4 → 入侵预兆或窗口毛边5
- 单元承诺：她从独活余味里出发；已准备过一个月；满级且想退休；陆昭不配当主冲突
- 单元情绪引擎：空 → 勉强笑 → 决意出发 → 跳月后的戒备冷 → 短确认「能打」→ 仍声明不卷
- 卷级贡献：兑现前期书名气质《Level Max 后我想退休》；落地开篇硬结构
- 主角局部目标与核心利益：确认今生可护的人还在；守住躺平；不暴露满级
- 因果入口：独活终点的海景屋顶 → 一个月后的重生现实
- 核心阻碍：独活创伤；月内布局毛边；周晏可能想冲；陆昭噪音（可选）
- 关键选择与决定性行动：选择「出发并躺平」而非继续颓废；对陆昭选无视/使坏而非开局对打
- 兑现方式与归属：满级可见（对读者/对女主）；周晏约上；收益归女主知情权与布局权
- 本单元主推线/战果：主推信息线；战果跳月成立、周晏接上；陆昭降权
- 本单元在跑的线：L01 立规矩；L02 约上闺蜜；L03 埋入侵；L05 可选插曲
- 终局底牌边界：不解释寿命抽离；不点名运；不揭价码；不展开顾衡全案
- 禁止提前释放：寿命规则课；开局呼晕陆昭大戏；前世长篇回忆
- 下一单元因果钩子：游戏正式入侵/登录窗口打开
- 本单元冲突：C01–C06
- 风险等级：契约安全
