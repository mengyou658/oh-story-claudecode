# 力量体系

## 显层：游戏面板
- 等级 / 职业 / 技能 / 装备 / 称号
- 沈晚宁开局 **无限**（橱窗用）；成长线对她是「调用库存」不是「从零练级」，她只要活着就在攒寿命，用寿命可以直接兑换等级
- 旁人仍走常规升级，形成信息差

## 隐层：寿命
- 见 `寿命与通关费.md`
- 战力再高，寿命归零也会在现实倒下
- 故「满级」≠无敌；后期公共危机卡的是命，不是等级

## 更深隐层：运
- 抽离寿命时一并剥夺的气运/机缘权重
- 中期只表现为「死醒后运气不对」；中后期才渐渐发现是「运」被夺
- 禁止当开局外挂说明书

## 台阶（与题材定位一致）
1. 个人摩擦与小丑插曲/小公会
2. 世家/头部公会机缘战
3. 特事局交易与高危权限
4. 异界/深本与寿命枯竭潮
5. 规则源头

女主战力台阶主要体现在「调用手段的稀缺与暴露成本」，不是再刷一级。
