# 核心设定表

### 基本信息
- 书名：前世薅完重生者，这世我不卷了
- 书名卖点分配：
  - 前期卖点：Level Max 后我想退休 — 开局确认重生 + 面板满级 + 四下无人一巴掌呼晕渣男；证明她「能打但不想打」
  - 后期卖点：重生后我只想陪闺蜜躺平 — 中后期主锚是陪闺蜜过日子；危机来了才被动出手，格局抬升仍守「不出头」
  - 贯穿卖点：前世薅完重生者，这世我不卷了 — 中段穿插前世：发现身边人重生 → 一路薅羊毛抢机缘 → 逼出重生秘密 → 手刃 → 自己却回来了；今生选择躺平
- 题材/类型：游戏入侵 + 重生信息差（女频）
- 目标平台：番茄
- 预计字数：120–180 万字（快节奏长篇）
- 目标读者：番茄女频游戏体育；爱信息差、私下搞事、闺蜜日常，厌无脑路人嘲讽打脸
- 读者契约：看一个「账已结清」的满级女主被迫再上场——她不出头、私下结算、陪闺蜜；命价规则后期翻盘，不是开局复仇饥渴
- 主角高光/代理权：她独占「谁该死几次、谁的命数被抽、何时对国家开口」的判断与结算；旁人可执行，不得夺走私下处理的因果权
- 核心期待债：①她为什么能满级回来 ②命数到底是什么、她在死局里抽了什么 ③她会不会为了谁再次花命

### 一句话梗概
前世跟重生者薅到世界尽头、仇报完却独活到买不起寂寞，沈晚宁用寿命买回第二次人生，只想陪闺蜜躺平——游戏再次入侵时她被动应战、暗抽命数，直到世人挖出规则，她才不得不把命押上更大的棋盘。

### 主角设定
- 姓名：沈晚宁
- 年龄：重生落点约 22（外表）；实际独活岁月对外保密
- 核心特质：结算完毕、懒得出头、下手干净
- 金手指/核心能力：
  1. 前世满级面板与完整情报（Level Max）
  2. **命数感知/抽离**（中期起暗用）：死亡发生时，可暗中抽走部分命数入库；世人后期才挖出「死多了会没空命数→昏迷/真死」
  3. 已付清的重生资格（用独活寿命购买）——规则细节后期揭示
- 弱点/缺陷：情感钝化、不愿当先锋、对「再失去一次」过敏；抽命数有暴露与道德余震
- 核心动机：陪闺蜜把这辈子过舒服；其余能避则避，避不了就私下一次结清

### 世界观骨架
- 时代/背景：近未来都市；某日「游戏」入侵现实，登录/副本/死亡开始改写社会规则
- 核心设定：**命数**是死亡与重生的底层通货。游戏内死亡消耗命数；命数耗尽→现实昏迷或死亡。沈晚宁中期起在死亡事件中暗抽命数；该机制被世人挖掘属后期节点
- 力量体系：游戏等级/职业/技能面板 + 命数库存（隐）+ 官方特事接口
- 社会结构：民间玩家乱战 → 世家/公会争机缘 → 国家特事局间接收编合作（女主只做交易不做先锋）

### 核心冲突
- 主线矛盾：世界逼她出头 vs 她坚持躺平私下处理；命数规则从个人暗线变成公共危机
- 终极 Boss/终极阻碍：吃光命数的规则源头 / 把「死人当耗材」的上位存在或体制（终局卷解锁，不提前打光）
