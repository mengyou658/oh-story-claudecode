# 沈晚宁（女主）

## 基本
- 身份：重生满级玩家；表面普通都市女青年
- 年龄：重生落点 22 岁上下
- 定位：躺平结算者；不当先锋

## 性格
- 关键词：懒得出头、下手干净、账目清楚
- 说话：短句、少解释；对闺蜜才软一点
- 行为准则：周围有人 → 避锋芒；周围无人 → 一次结清；国家线 → 只谈交换不谈理想；前男友 → 当小丑，无视或私下使坏

## 能力
- 面板：Level Max（开局可验证）
- 情报：前世完整版本经验 + 跟过重生者的「薅法」
- 寿命：中期起可在死亡发生时暗抽寿命入库；库存可用于抵扣、交易、后期救特定之人
- 运：抽寿命时顺带剥夺；她自己中后期才渐渐发现
- 禁：开局不展示抽寿命；不点名讲运；不主动刷路人打脸；不开局把陆昭当主冲突打

## 动机
- 表层：陪周晏把日子过好
- 深层：怕再经历一遍「所有人都先走了」的独活（开篇照片即此）
- 底线：必要时可花自己的命，但不许世界拿她当先锋燃料

## 弧光
已结算 → 被迫再上场 → 学会在躺平与花命之间选一次真正值得的账（救秦小源是中点，不是终点）
