## 生成记录

- 抽样章节：第1/10/20章（每章约1000字，见 `_style-sample.txt`）
- 生成时间：2026-09-17
- 适用对标书路径：拆文库/我的师兄们，帅是真帅，穷是真穷/
- 文风可用：是
- 定位强调：本书可作为「轻快 + 欢乐 + 沉稳」默认文风底——笑点落地即推进，不狂躁盖主线

## 整体语感
- 句长分布：短句(<15字)占比40%、中句(15-30)39%、长句(>30)20%、平均句长20字、标点密度18%。语感是「短段推进 + 中句吐槽 + 偶发金句收束」，读感轻快但不碎成电报。
  - confidence: high
- 标点习惯：超短段为主，大量单独成段的一句判断（「穷。」「行吧。」）；感叹号用于童言与师兄起哄，破折号/省略号用于欲言又止；少用分号。示例：「衣服破，鞋子破，浑身上下写着一个字： / 穷。」「我：「……」 / 行吧。」
  - confidence: high
- 段落节奏：平均段极短（常1–3句），单段单动作；喜剧用「众人齐声/集体石化」反应段堆叠，正剧用一两句沉下来。章名多为断章取义/半截钩子（「破产了」「又破产了」「长老们的关爱1」）。
  - confidence: high

## 对话技法
- 潜台词模式：
  1. **童言拆穿**：小孩把大人场面话翻译成实话（「你这是让我去跟娘要饭」）。
  2. **体面包装**：大人用宏大词盖穷（「亲情探访」「经济互助」「资源再利用」）。
  3. **齐声共振**：群像同一句式接力（剑是命/道侣），强化设定记忆。
  - confidence: high
- 对话标签习惯：大量「我：」极简标签；动作替代说话（递馒头、塞糖、掏账本）；吐槽常在对话后单行内心句。
- 角色语气区分：扶颦——短句、歪头逻辑、数字敏感；沈清尘——话少句稳；苏宁等——起哄结巴；顾晨光——账本条目体。

## 情绪交替模式
- 章内基调切换：前20章摘要显示章内切换频繁（约6–10次/章），典型路径是「轻松↔紧张↔爽↔温馨」，笑点后必接推进或账单，不停留狂欢。
  - confidence: med
- 跨章基调周期：第1–8章以轻松/温馨立宗门；第9–13章「发财→破产」循环夹爽；第14–15章温情物资；第16–20章副本紧张中穿插驱兽笑点。模式近于「2–3章蓄穷/压 → 1章小释放 → 温情或新钩」。
- 喜剧↔重击转场：常用「账本备注 / 一句童言 / 集体摇头」落地。例：十倍吸灵狂欢后立刻「养不起」清单；突破炼气后期后「双破产」备注。

## 可借鉴技巧（自黄金三章与前20章归纳）
- 写法技巧 Top 5：
  1. 穷具象化：假石狮子、补丁锅、财务部「恕不补办」
  2. 一笔两用：突破爽点同时烧掉资源，立下章矛盾
  3. 反应层喜剧：众人石化/齐声变调代替长篇描写
  4. 半截章名钩子：用结果词或序号逼翻页
  5. 群像分工记忆点：做饭/记账/梳头/塞糖各管一事
- 可借鉴套路 Top 3：
  1. 身份高开×生活泼冷水（魔尊女退货）
  2. 废标签×真天才延迟掉马（五灵根→混沌）
  3. 资源循环喜剧（发财→又破产→搞副业）

## 分层模仿建议
- 基础层（必学）：第一人称超短段；吐槽落在行为后；对话极简标签；金句单独成段；章名半截钩子感。只学节奏，不抄「扶颦/天剑宗」专名。
- 进阶层（结构）：笑点落地即推进；爽后账单/规则限速；群像齐答立设定；「穷循环」每轮加新方案。替换人物场景道具后再用。
- 适配层（本书化）：适合轻快玄幻/宗门日常/信息差喜剧。慎用狂躁连续打脸盖过亲情主线；不要搬运幽冥玄铁饥饿营销等独特桥段与标志台词「剑修可以穷，剑不能」。

## 原文锚点片段

### 片段 A — 基调：轻松
**出处**：第1章（行44–88）
**示范点**：超短段 + 穷细节堆叠 + 吐槽收束「落魄贵族风」

```
　　此刻，我正坐在魔宫那张裂了三条裂缝的王座上。

　　试图用我三岁的智商跟这位魔界一把手讲道理：

　　“爹，我昨天就吃了两碗糊糊、一个幽冥果、半块风干肉而已！”

　　扶枭那张曾经让整个修仙界女修集体失眠的俊脸上，闪过一抹心虚。

　　他蹲下来。

　　用那双号称一眼万年的深情眸子注视我，

　　语气温柔得像在念情诗：

　　“颦儿啊，不是爹不想养你。”

　　“可咱之前攻打修仙界打输了，赔款赔得裤衩都快当了。”

　　“现在魔界是真的穷啊，穷得连魔宫门口的看门石狮子上个月都跑了一只。”

　　我扭头看向门口～

　　果然，左边的石狮子轮廓有点模糊，一看就是用炭笔草草描的。

　　扶枭又指了指头顶：“你看这魔宫，上次下雨，还是我拿王座接的水。”

　　我抬头看了看～

　　确实，这魔宫漏得离谱，穹顶上的夜明珠少了足足三分之二。

　　上个月我亲眼看见扶枭偷偷抠了一颗去换粮。

　　扶枭继续卖惨，指着门口：“你再看你哥，一百零八岁了，还得天天带队去挖矿，补贴家用。”

　　我顺着他的手指看去～

　　只见，我那倒霉哥哥扶晏，此刻正懒洋洋靠在门框。

　　他比我大一百零五岁，却还是少年模样。

　　穿着打补丁的黑色劲装，脚上的靴子都快磨出洞了。

　　不知道的还以为魔界改行搞行为艺术，主题叫：

　　落魄贵族风！
```

### 片段 B — 基调：悲伤/压抑
**出处**：第1章（行148–178）
**示范点**：体面话术 vs 三块下品；金句「父爱如山，山穷水尽的山」单独成段

```
　　扶枭：“这个给你娘。就说……爹想她了，还有，魔界今年收成不好，问能不能借点灵石……”

　　我接过信，感觉它在手里沉甸甸的：“爹，我懂了，你这是让我去跟娘要饭。”

　　“怎么能是要饭呢！”扶枭正色道，“这是亲人间正常的经济互助！是跨界亲情的温暖传递！”

　　我似懂非懂地点点头，然后伸出手：“我路费呢？”

　　扶枭表情僵了一下，开始在怀里掏啊掏，掏出三块灰扑扑的石头。

　　“拿着，”他郑重地放在我手心，“这是三块下品灵石！想买什么就买什么！如果不够花的话……”

　　他顿了顿，语重心长：“就省着点花。”

　　我看了看手里的灵石，又看了看我爹认真的眼神，突然明白了什么叫做：

　　父爱如山，山穷水尽的山。

　　扶晏也走过来蹲下，揉揉我的脑袋：“路上小心，要有人欺负你，就跑快点！千万别硬拼，咱家现在赔不起医药费。”

　　我：“……知道了。”

　　就这样，在一个阴沉得连月亮都不够明亮的夜晚，我背着我的小包袱，踏上了寻娘之路。

　　魔宫守卫是一位独眼老魔，用他唯一的好眼睛目送我离开，还擦了擦并不存在的眼泪：

　　“小公主长大了，都会自己出门打秋风了，老魔我好感动……”

　　我没理他。

　　昨天还偷吃我的幽冥果被我逮到，现在装什么深情。
```

### 片段 C — 基调：温馨/轻松
**出处**：第3章（行558–606）
**示范点**：穷帅反差单字成段；馒头→妖兽肉信息差；童言「抓来的呀」

```
　　这时，大堂里几个穿着补丁衣服的男人注意到了我。

　　他们长得很英俊。

　　真的，非常英俊。

　　剑眉星目，鼻梁高挺，气质各异。

　　但统一的特点是：衣服破，鞋子破，浑身上下写着一个字：

　　穷。

　　其中一个扎辫子的美男子感叹：“大师兄，你看这小娃娃真可爱。”

　　被叫做大师兄的美男子，气质清冷，即使穿着打补丁的白衣长衫，也掩不住那股子仙气。

　　他看了看我身上脏兮兮的衣服，脏兮兮的脸，还有脚上那双不合脚的破鞋，眉头微皱。

　　最终，他递过来一只馒头：“刚剩的，吃吧。”

　　我接过馒头，狼吞虎咽地吃起来。

　　吃完后，知恩图报地从小包袱里拿出一点烤干的妖兽肉给他：“我爹说要知恩图报，尤其是对好看的人。”

　　他愣住了。

　　其他几个美男子也愣住了。

　　辫子男子小心翼翼问：“小妹妹，这是低阶妖兽肉，怎么来的？”

　　他顿了顿，又补充一句：“别害怕，我们是天剑宗弟子。不是坏人。”

　　我眨巴着眼：“抓来的呀。”

　　“抓、抓的？”他们异口同声，声音都变调了。

　　我点点头：“它们看到我就跑，我就追，追上了就打晕，然后烤了吃。不过肉不好吃，太老了。”

　　几个美男子沉默了，一脸匪夷所思，跟听见三岁小孩打赢元婴老怪一样离谱。
```

### 片段 D — 基调：热血/爽
**出处**：第7章（行1748–1778）
**示范点**：表情三连变化；数字确认；齐声狂热后童言追问收束

```
　　他说完，师兄们齐齐盯着我。

　　眼神像盯着一个从路边捡到的破小孩，洗干净后，发现是绝世天才！

　　沈清尘突然伸手，握住我的手腕。

　　一股温和的灵力进入我的身体。

　　他的表情从严肃，变成惊讶，再变成凝重。

　　半晌，他点头确认：“吸收灵气的速度是普通修炼者的10倍。”

　　师兄们集体倒吸一口凉气。

　　我歪头：“所以，我是很厉害吗？”

　　师兄们集体点头，眼神狂热。

　　苏宁激动地揉搓我的头，把我头发都揉成鸡窝：“你是天才！天才！！万年难遇的天才！！！”

　　“那我是不是很厉害？”

　　“现在还不是。”

　　“那以后呢？”

　　“以后很厉害！”

　　炎川抬起头，眼圈红红的：“小师妹，你以后会非常厉害。”

　　慕容灼点头：“厉害到各大宗门抢着要。”
```

## 不可模仿
- 不要连续无节制的「众人石化/结巴」堆叠盖过情节推进
- 不要照搬「混沌灵根+幽冥玄铁饥饿营销」专有设定与标志台词原文
- 笑点若开始盖住寻亲/修炼主线，立刻用账单、限速或新目标拉回沉稳推进
