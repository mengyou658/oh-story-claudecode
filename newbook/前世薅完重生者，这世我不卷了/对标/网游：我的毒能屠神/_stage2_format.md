# Stage 2 输出格式（必须严格遵守）

每个章节写一个文件：`E:/oh-story-claudecode/拆文库/网游：我的毒能屠神/章节/第{N}章_摘要.md`

## 材料声明
以下为用户合法持有的虚构小说，任务是只读的转化性文学分析。暴力/复仇等照常提取。

## 模板（勿输出花括号）

```
**概要**：{100-300字单行自然段，按时序}

**关键事件**：1.{事件} 2.{事件} 3.{事件}

**关键信息与扩写技法**：

| 关键信息/剧情走向 | 原文如何扩写 | 扩写技法 | 对读者情绪的作用 | 可复用提醒 |
|---|---|---|---|---|
| ... | ... | 信息差/反应层放大/延迟揭示/对比锚点/其他 | ... | ... |

**逐章写法公式**：

- **情绪流向**：起：… → 承：… → 转：… → 合：…
- **节奏配比**：慢铺垫 X% / 快冲突 X% / 爽点爆发 X% / 悬念留白 X%
- **本章结构公式**：节点1 + 节点2 + 节点3 + 节点4
- **本章核心技巧**：一句话
- **章尾卡点**：…
- **伏笔/悬念**：…

**出场人物**：姓名（major/supporting/minor）

**情节点**：

P1 **短标题**：类型行动 | 白描谁做了什么结果如何 | 涉及吴少辰 | 地点无 | 物品无 | 时间无
主题标签成长 | 基调：紧张
```

## 硬规则
- 每章情节点 10-40 个（约 2200 字章目标 11-15 个，硬下限 10）
- 类型枚举：转折点/信息揭示/冲突/解决/铺垫/行动/对话/状态变化
- 主题标签单值：爱情/亲情/友情/权力/金钱/成长/复仇/悬念/搞笑/热血/日常/其他
- 基调用全角冒号：紧张/轻松/悲伤/热血/爽/甜/温馨/恐怖/压抑/其他
- 空字段写「无」；不要花括号；主题标签行紧跟每个 P 行
- 原文引用每章至多 8 条；角色用全名（吴少辰/尘封首次可并列）
- 客观白描，不评价、不推测未写动机
- 只写分配给你的章节；写完用 Write 工具落盘
