# 第11章 狗运
周晏傍晚推门进来，裤脚沾灰，怀里却抱着一只不起眼的哑光匣子。匣子一开，面板跳出两行灰字：低危续航晶片×3，边缘积分+40。不起眼，却够她下三次短刷。
“稳！”她把匣子往茶几上一搁，声音压不住，“你那条线邪门，我进去十分钟就刷到，旁边有人空转半天。”
话到一半她顿住，目光往沈晚宁脸上飘：“你教的路——”
“狗运。”沈晚宁打断，把匣子盖上，“自己摸的。别在群里晒。柜子里。”
周晏嘴一瘪，还是听话塞进柜子最里层。窗外有人路过，故意放慢脚步，嘀咕一句“又她”，声音很快被风吹散。沈晚宁记下那截帽檐的角度。
夜里私聊弹了。陌生头像，语气不阴不阳：边缘带那条线，谁教的？坐标怎么卡得这么准？
周晏打到“朋友”两个字，拇指悬着。沈晚宁从沙发后伸手，按灭屏幕：“口径还没定。别回。”
“那人家盯着……”
“让他盯。”沈晚宁把对方 ID 截进本地，“你先别开口。”
盘问者连发三条，最后丢下一句“走着瞧”，灰了。周晏后怕得搓手心。
沈晚宁把她按到餐桌前，纸笔摊开，只写三句：
一，狗运。二，自己摸的，别细讲。三，路线不外传，问就装傻。
“以后就这么说。”她示范一遍问答，像过安检。“来，你念。”
周晏念得别扭：“像背台词。”
“台词能保命就背。”沈晚宁把笔递给她，“对外就这三句。勾一下。”
周晏咬唇，在备忘录里新建条目标题：听晚宁的·对外版，勾选完成。手机震了一下——城北边缘带流量预警，人比首波多。
沈晚宁看了一眼预警，把窗帘拉严：“明天更挤。话术先装进嗓子里。”
周晏把备忘录置顶，小声：“我就说一句朋友教的会死吗？”
“会死清净。”沈晚宁关灯，“睡。明天你走你的线，我在阴影里。”
