# 选题决策：跨平台全榜（无预设方向）
- 扫榜日期：20260916
- 数据来源：同目录起点 10 榜、番茄男/女频阅读榜全题材、晋江收入金榜、七猫男女大热日榜；详见 `扫榜报告_跨平台全榜.md`
- 作者条件：本次未声明擅长题材/素材/目标平台 → **可行性一律不超过「中」**（差作者匹配不能给「高」）

## 推荐选题

### 选题 1：诡异规则求生 · 低门槛日常壳 + 真死代价
- 题材组合：无限/规则怪谈 + 宿舍/职场/广告等日常入口（可切男频孤狼或女频群像）
- 目标读者：番茄脑洞读者（主）；能写硬设定再开起点付费向加长
- 核心卖点：开篇像日常翻车，规则一翻就是命；每章有可结算的「活下来条件」
- 能爆的原因：番茄男频悬疑脑洞#1《十日终焉》179.9 万在读，女频《宿舍求生：从刷广告开始变强》45.1 万；书名「求生」男 7 / 女 9 本重复。不是单本个例（假设，`待拆文验证`）
- 差异化定位：不写老派副本说明书；入口必须「读者自己的房间/宿舍/通勤」，第一次真死代价出现在黄金三章内
- 可行性：中 — 番茄两侧样本均 ≥15 且趋势↑；作者未声明克系/副本素材，先验证再加码
- 失败风险：规则堆砌劝退；中期变成打怪升级；和《十日终焉》气场撞车
- 验证动作：先写黄金三章（误入规则→第一次真死/假活→可交易的唯一豁免）测完读；不行就换入口壳不换内核
- 篇幅/平台：番茄 80–200 万快节奏为主；若追读稳再考虑起点加世界观向 200 万+

### 选题 2：金手指「对公交付」· 系统想害我 / 上交国家
- 题材组合：都市脑洞 + 异能/系统反向 + 体制或组织博弈
- 目标读者：番茄都市脑洞/高武（在读头部 158–173 万）；起点已有《请勿高考时渡劫》《急急如律令》证明现代异能可打阅读收藏
- 核心卖点：外挂不是私有开挂，是绩效、上交、被组织看见；爽点来自「把私货做成公器」
- 能爆的原因：番茄都市脑洞#1 即该结构；标签「上交国家」「双向奔赴」跨都市脑洞重复；与纯无敌文形成情绪差（假设，`待拆文验证`）
- 差异化定位：系统明确想坑主角，主角用规章/证据链反将；不写无脑爱国口号，写流程和人情债
- 可行性：中 — 流量样本足够，跟风也快；需要一点体制/职场素材，没有就不要硬写部委
- 失败风险：审核与空洞口号；金手指无限制导致无敌；读者觉得说教
- 验证动作：黄金三章只打「一次上交、一次反噬、一次公开记账」；看评论是否骂说教
- 篇幅/平台：**主投番茄**；起点可改成更冷的现代修仙/猎魔困境版（见扫榜「反常识书名」簇）

### 选题 3：末世不是砍丧尸 · 供应商 / 安全屋 / 跟买情报差
- 题材组合：科幻末世 + 经营囤货（男频供应商 / 女频跟重生者买买买 / 晋江安全屋言情或无 CP）
- 目标读者：晋江金榜求生簇 + 番茄末世男#1《末日生存方案供应商》、女#1《极寒末世，我跟着重生者买买买》
- 核心卖点：活下来靠库存、图纸、情报时差，打架是结算不是日常
- 能爆的原因：晋江安全屋/囤货/求生约 17 本成簇；番茄男女末世头部都不是纯尸潮无双（假设，`待拆文验证`）
- 差异化定位：不做全图开挂仓库；核心冲突是「别人也知道你有货」之后的定价权
- 可行性：中 — 三平台重复样本够；经营文中期易写成流水账，必须先定交易规则
- 失败风险：清单文；女频变纯宠后丢掉求生压力；男频变战争文丢掉经营
- 验证动作：首卷只跑「三种物资三种对手」；黄金三章完成第一次被抢单/被跟单
- 篇幅/平台：番茄/晋江看你的情感线密度；要付费长线再评估起点科幻，不建议同一稿三平台
