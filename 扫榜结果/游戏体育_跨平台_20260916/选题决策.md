- 数据来源：同目录起点游戏 chn7 五榜；番茄游戏体育男/女阅读 + 男新书；女新书标题异常仅作弱参考。对照同日 `跨平台_全榜_20260916`。
- 作者条件：本次未书面声明擅长素材/目标平台 → **可行性一律不超过「中」**（你若主攻起点异界或已有「命价/通关费」素材，可口头升级后再重评）

## 推荐选题

### 选题 1：游戏异界 ·「假游戏真死」+ 可标价的唯一资源
- 题材组合：游戏异界 + 生存/权限市场（非纯数值横推）
- 目标读者：起点男频，接受硬设定、要中后期格局的付费读者
- 核心卖点：入场以为打本，规则一翻是命；主角握有「别人不敢用/买不起」的交换物
- 能爆的原因：月票+畅销双#1《浊世游戏》，同向还有《异维囚笼》《升格耀变体》《这里不欢迎玩家》（新人签约）；假游戏真死不是单本个例（假设，`待拆文验证`）
- 差异化定位：不做机械师/琥珀面板复刻；主线是情报/命数/通关权市场，战斗是结算不是日常
- 可行性：中 — 同方向起点样本 ≥15 且趋势→；作者未在本扫声明世界观素材，故不给「高」
- 失败风险：中期变普通升级文；真相揭太早/太晚；和《浊世》《惊悚乐园》气场撞车
- 验证动作：黄金三章只打「入场误解 → 第一次真死代价 → 第一次资源/命价交易」；追读不行就换壳不换内核
- 篇幅/平台：200–400 万字；**主投起点**；番茄需另开快节奏短连载壳，不建议同一稿双投

### 选题 2：番茄向 · 游戏入侵「抢机缘 / 退游日常」快节奏
- 题材组合：游戏入侵 + 无 CP 升级或轻甜日常（二选一锁死）
- 目标读者：番茄女频游戏体育（主）/ 男频可吃退游日常
- 核心卖点：信息差开局（重生截胡内测 / 退游一句引出 NPC）；每章可结算的抢夺或反差
- 能爆的原因：女频阅读#1《游戏入侵：抢男女主机缘…》**106.9 万在读**；男频《退游六年…》从新书爬到阅读#7（23 万）——入侵日常已被验证能留存（假设，`待拆文验证`）
- 差异化定位：女频避开纯恋爱挂机，锁「抢资源上瘾」或「大女主独狼」；男频避开列车换皮，走入侵后的现实摩擦
- 可行性：中 — 流量样本充足但跟风密；女频新书标题本次未解全，供给侧判断打折
- 失败风险：中期变无脑打怪；甜宠盖过危机；和《游戏入侵》人设撞车
- 验证动作：先更 30–50 章测完读；黄金三章必须完成「第一次截胡/第一次现实后果」
- 篇幅/平台：**主投番茄**；80–200 万字快节奏

### 选题 3：番茄向 · 热游电竞直播（三角洲等）技术碾压日常
- 题材组合：电子竞技 + 直播弹幕 + 单女主或无女主
- 目标读者：番茄男频，玩过或围观该热游的流量读者
- 核心卖点：名场面复盘 + 直播情绪；简介可声明「没玩过也能看」降门槛
- 能爆的原因：男阅读《三角洲：FPS暴君降临》23.3 万；新书《三角洲：这野人魔了…》等重复；与起点 LOL 红海错位，追的是**当下热游**（假设，`待拆文验证`）
- 差异化定位：退役/雪藏回归直播，不写又一遍世界赛流水账；章节短、爽点密
- 可行性：中 — 样本够但窗口短，IP 热度掉则流量掉；不适合当唯一长线主业
- 失败风险：版本改设定过期；纯技术描写劝退；与录播无差异
- 验证动作：绑「仍在爆发的赛季/模式」试 30 章；不行立刻停损
- 篇幅/平台：**主投番茄**；不指望起点月票
